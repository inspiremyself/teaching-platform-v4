### 3.1 现网核对结论

1. `question_bank.code` 为 `VARCHAR(64) NOT NULL UNIQUE`（[V1__init_schema.sql](file:///Users/liangzai/CursorProjects/teaching-platform-v4/backend/src/main/resources/db/migration/V1__init_schema.sql#L58-L71)），22 字符编码安全；后端 `normalizeCode` 统一 `trim().toUpperCase()`，因此随机位必须大写，否则同秒展示值与落库值不一致。
2. `QuestionService.create/update` 仅做编码唯一性判断与 JSON 合法性校验，无题型白名单；编码冲突返回 `40900`（[QuestionService.java](file:///Users/liangzai/CursorProjects/teaching-platform-v4/backend/src/main/java/com/opencode/teachingplatform/question/service/QuestionService.java#L41-L64)）。
3. 后端测试中所有 `CODE` 断言都位于 `lab` 包（`LabServiceTests`、`BehaviorIngestServiceTests`、`LabBehaviorMetricsServiceTests`），题库测试无 `CODE` 断言，因此题型收敛不需要改后端测试。
4. `setKind` 唯一调用方是 `QuestionEditorDialog`（[QuestionEditorDialog.vue](file:///Users/liangzai/CursorProjects/teaching-platform-v4/frontend/src/components/question-config/QuestionEditorDialog.vue#L294-L297)）；`LabSteps.vue` 走 `applyHydratedState` 自行 hydrate，返回值变更无影响。
5. `TypedEditorShell` 有两个使用方（题库弹窗与 `LabSteps.vue`），因此门控放在弹窗侧，壳层不动。
6. `Homeworks.vue` 的 `currentEditorQuestion` 在「新增内联题」时返回 `null`、编辑时返回当前项（[Homeworks.vue](file:///Users/liangzai/CursorProjects/teaching-platform-v4/frontend/src/views/teacher/Homeworks.vue#L360-L401)），因此 `editing` 必须由调用方显式传入，不能用 `initialQuestion` 是否为空推断。
7. `buildQuestionPayloadFromDraft` 现网共 5 个调用点：`Questions.vue` L484、`exams/List.vue` L704、`Homeworks.vue` L497（内联题组装）与 L675（题库题保存）、`labStepAdapter.ts` L113（实验步骤同步题库）；options 增加必填 `type` 后五处都必须改，否则 `vue-tsc` 直接报错。

```ts
export type QuestionType = 'SINGLE' | 'MULTI' | 'JUDGE' | 'FILL' | 'SHORT';
export type QuestionDifficulty = 'EASY' | 'MEDIUM' | 'HARD';

```

```ts

export const ALL_TYPED_EDITOR_KIND_OPTIONS: TypedEditorKind[] = ['SINGLE', 'MULTI', 'JUDGE', 'FILL', 'SHORT', 'TEXT', 'CODE']; // 不变
export const QUESTION_TYPED_EDITOR_KIND_OPTIONS = ['SINGLE', 'MULTI', 'JUDGE', 'FILL', 'SHORT'] as const; // 移除 CODE
```

```ts
// adapters/questionAdapter.ts
export const normalizeQuestionType = (type?: string | null): QuestionType => {
  if (type === 'TEXT') return 'SHORT';
  if (type === 'SINGLE_CHOICE') return 'SINGLE';
  if (type === 'MULTIPLE_CHOICE') return 'MULTI';
  if (type === 'TRUE_FALSE') return 'JUDGE';
  if (type === 'FILL_BLANK') return 'FILL';
  return type && isQuestionType(type) ? type : 'SINGLE';
};

interface BuildQuestionPayloadOptions {
  code: string;
  type: QuestionType;
  difficulty: string;
  defaultScore: number;
  analysisText: string;
}

export const buildQuestionPayloadFromDraft = (
  draft: TypedEditorDraft,
  options: BuildQuestionPayloadOptions,
): SaveQuestionPayload => {
  const serialized = serializeQuestionDraft(draft);
  return {
    code: options.code.trim(),
    type: options.type,
    stem: draft.prompt.trim(),
    difficulty: options.difficulty,
    defaultScore: options.defaultScore,
    optionsJson: serialized.optionsJson,
    answerJson: serialized.answerJson,
    analysisText: options.analysisText.trim(),
  };
};

const pad2 = (value: number) => String(value).padStart(2, '0');

/** 题目编码：本地时区 yyMMddHHmmss + 4 位大写 base36 随机位，展示值与落库值同源 */
export const buildQuestionCode = (type: QuestionType): string => {
  const now = new Date();
  const stamp = `${pad2(now.getFullYear() % 100)}${pad2(now.getMonth() + 1)}${pad2(now.getDate())}`
    + `${pad2(now.getHours())}${pad2(now.getMinutes())}${pad2(now.getSeconds())}`;
  const suffix = Math.random().toString(36).slice(2, 6).padEnd(4, '0').toUpperCase();
  return `Q-${type.slice(0, 3)}-${stamp}${suffix}`;
};
```

`serializeQuestionDraft` 由导出去掉 `export`（仅模块内使用），`CODE` 分支不在题库路径复用；`PersistedQuestionType`、`serializeQuestionType` 整段删除。

#### 4.3.1 `setKind`


#### 4.3.2 `syncFillBlanks`

```ts
const syncFillBlanks = () => {
  const previous = draft.fillBlanks;
  const matches = Array.from(draft.prompt.matchAll(/【填空(\d+)】/g));

  if (!matches.length) {
    draft.fillBlanks = [];
    return;
  }

  let normalizedPrompt = '';
  let cursor = 0;
  const nextBlanks: TypedEditorBlankDraft[] = matches.map((match, occurrenceIndex) => {
    const originalIndex = Number(match[1]);
    const nextIndex = occurrenceIndex + 1;
    const positional = previous[occurrenceIndex];
    const answersText =
      positional && positional.index === originalIndex
        ? positional.answersText
        : previous.find(blank => blank.index === originalIndex)?.answersText ?? '';

    normalizedPrompt += draft.prompt.slice(cursor, match.index) + `【填空${nextIndex}】`;
    cursor = (match.index ?? 0) + match[0].length;

    return { index: nextIndex, token: `【填空${nextIndex}】`, answersText };
  });

  normalizedPrompt += draft.prompt.slice(cursor);
  draft.prompt = normalizedPrompt;
  draft.fillBlanks = nextBlanks;
};
```

取值优先级写死为「同位置同编号 → 原编号查找 → 空字符串」。三空删中间、乱序编号、重复编号三种场景均由同一规则覆盖；重复编号两处均取到该编号的同一答案，且不会串位。

## 6. 数据流与接口契约

### 6.1 新增题目（成功）

1. `openCreateDialog` → `resetForm` → `dialogVisible = true`。
2. 弹窗 hydrate：默认单选、4 个空选项、`lockedCode` 生成一次、基线落定。
3. 教师填写，`validationVisible` 转真，缺失项实时更新。
4. 提交：`submitAttempted = true` → 校验通过 → `saved` 事件带 `{ code: lockedCode, type: form.type, draft }`。
5. 页面 `buildQuestionPayloadFromDraft` 组装 → `POST /api/v1/questions`。
6. 成功：关闭弹窗、`resetForm`、刷新列表。

### 6.2 新增题目（失败）

1. 后端返回 `40900` 或 4xx/5xx，`request.ts` 统一提示错误。
2. `loading` 由真转假且弹窗仍可见：草稿不变，`lockedCode` 重新生成（仅非编辑态）。
3. 教师再次提交，使用新编码；成功路径不变。

### 6.3 编辑题目

1. `openEditDialog` 写 `form` 与 `editingId`，弹窗按该题归一题型 hydrate，`lockedCode` 取原编码。
2. 提交 payload 的 `code` 为原编码、`type` 为当前题型；后端 `PUT /api/v1/questions/{id}` 不变。

### 6.4 后端与数据库

| 项 | 结论 |
|---|---|
| 接口 | `POST/PUT/GET /api/v1/questions` 契约不变 |
| 校验 | 仍只有 `@NotBlank code`、编码唯一、JSON 合法性；题型不做白名单 |
| 数据库 | 无迁移、无表结构变更；`code` 仍 `VARCHAR(64) UNIQUE` |
| 错误码 | 冲突仍 `40900 题目编码已存在`；权限仍由 `createdBy` 约束 |

| 在 `TypedEditorShell` 增加 `showMessages` prop | 会把校验门控语义下沉到实验步骤域共享组件，扩大影响面；传空数组即可达到同等效果 |
