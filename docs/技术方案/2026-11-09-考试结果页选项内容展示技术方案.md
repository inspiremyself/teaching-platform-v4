# 技术方案：考试结果与批改页展示选项内容

**状态**：已定稿（决策写死，可直接编码）

## 1. 背景与目标

学生端考试结果页（`ExamAnswerPanel.vue` state `'C'`、`resultMode === 'result'`）与教师端考试批改页（`views/teacher/exams/Results.vue`）在客观选择题上只显示答案字母（如「你的答案 A」「参考答案 C」），页面不出现 A/B/C/D 各选项的文本内容，学生无法把字母对应到当时的选项，教师批改时也无法核对学生具体选了什么。

事实核查（本次调研已确认）：

- 快照 `ExamQuestion.questionSnapshotJson` / `QuestionSnapshot.optionsJson` 完整保存选项内容；
- 学生详情 `GET /api/v1/exams/{id}` 对每道题无条件返回 `optionsJson`（`ExamConfigService#getExamDetail`），成绩可见时额外返回标准答案 `answerJson`；
- 教师提交详情 `GET /api/v1/teacher/exam-submissions/{id}` 返回 `answers[].optionsJson` / `standardAnswer` / `studentAnswer`（`ExamReportService#getSubmissionDetail`）；
- 前端 `ExamQuestionView` / `ExamAnswerDetail` 均已声明 `optionsJson` 字段。

即数据链路不缺信息，缺失发生在两个页面的结果渲染层：只把答案字母当字符串输出。

目标：在上述两个页面的每道客观选择题卡片中展示该题的完整选项列表（字母 + 文本），并把「学生所选」与「正确答案」直接标注在对应选项行上。

## 3. 实现说明（选定路径）

### 3.1 `frontend/src/utils/examAnswer.ts`

```ts
export interface ExamOption { key: string; label: string }
export interface ExamOptionReviewRow extends ExamOption { selected: boolean; correct: boolean }

export function normalizeQuestionType(type?: string | null): string  // SINGLE→SINGLE_CHOICE / MULTIPLE→MULTIPLE_CHOICE / JUDGE→TRUE_FALSE，其余原样
export function isOptionQuestionType(type?: string | null): boolean  // 仅 SINGLE_CHOICE / MULTIPLE_CHOICE
export function parseQuestionOptions(raw?: string | Array<{ key: string; label: string }> | null): ExamOption[]
export function selectedOptionKeys(raw?: string | null, questionType?: string | null): string[]
export function buildOptionReviewRows(input: {
  optionsJson?: string | Array<{ key: string; label: string }> | null
  questionType?: string | null
  studentAnswer?: string | null
  standardAnswer?: string | null
}): ExamOptionReviewRow[]
```

- `parseQuestionOptions` 直接搬用现网 `parseOptions`（含 `"A.文本"` 前缀拆分、无 key 时按位置生成 `A/B/C`、`content/text/value` 兜底）。
- `selectedOptionKeys` 的 `kind` 判定与 `answerPayload.ts#buildAnswerPayloadJson` 的落库形态对齐（`{kind:'single'|'multiple', ...}`）。
- 所有比较统一 `toUpperCase()`，避免历史小写键（`["a"]`）失配。

### 3.2 `ExamOptionReview.vue`

```vue
<template>
  <section v-if="rows.length" class="exam-option-review">
    <div class="exam-option-review__title">选项明细</div>
    <ul class="exam-option-review__list">
      <li
        v-for="row in rows"
        :key="row.key"
        :class="['exam-option-review__row', row.selected ? 'is-selected' : '', row.correct ? 'is-correct' : '']"
      >
        <span class="exam-option-review__key">{{ row.key }}</span>
        <span class="exam-option-review__label">{{ row.label }}</span>
        <span v-if="row.selected" class="exam-option-review__tag is-selected">{{ selectedLabel }}</span>
        <span v-if="row.correct" class="exam-option-review__tag is-correct">{{ correctLabel }}</span>
      </li>
    </ul>
  </section>
</template>
```

`<style scoped>` 只定义 `.exam-option-review*` 类（BEM），不触碰父页面既有类。

### 3.3 `useExamDetail.ts`

- 删除私有 `parseOptions`，改为从 `@/utils/examAnswer` 引入 `parseQuestionOptions`，`resolveQuestionOptions` 内部调用它（导出名与签名保持不变，作答态行为零变化）。
- 返回对象中移除 `parseOptions`（已 grep 核对：仅 `resolveQuestionOptions` 内部使用，`ExamAnswerPanel.vue` 注入解构未取该项）。
- 其余逻辑（`formatDisplayAnswer` / `referenceAnswerText` / `resultAnswerMap`）不改。

### 3.4 `ExamAnswerPanel.vue`（仅 `state === 'C'` 结果区）

在每题卡片头部之后插入（`<style scoped>` 新增 `.exam-option-review { margin-top: 8px; }`，命中子组件根节点）：

```vue
<ExamOptionReview
  :options-json="question.optionsJson"
  :question-type="qType(question)"
  :student-answer="question.studentAnswer ?? question.answer"
  :standard-answer="canShowResult ? question.answerJson : null"
/>
```

`ExamOptionReview` 为普通静态 import（不通过 `ExamDetailKey` 注入）；`qType` 已在注入解构中存在；`optionsJson` 缺失时组件根节点不渲染，不产生空白间距。

### 3.5 `Results.vue`（批改页）

在 `question-card__body` 内、「学生答案」块之前插入：

```vue
<ExamOptionReview
  :options-json="answer.optionsJson"
  :question-type="answer.questionType"
  :student-answer="answer.studentAnswer"
  :standard-answer="answer.standardAnswer"
  selected-label="学生选择"
  correct-label="标准答案"
/>
```

## 6. 非目标

- 不改实验报告、作业结果的答案解析页（另立方案）。
- 不改后端快照结构、`ExamAnswerDetail` / `ExamQuestionView` 契约。

- 不做选项正误统计、选项分布图表、逐选项作答人数。
- 不新增折叠、搜索、导出等交互。

## 附录：已否决方案

| 否决项 | 原因 |
|--------|------|
| 只把答案块字母替换成「A. 文本」 | 学生仍需在两条答案之间来回比对，看不到其余选项；且正确答案与所选答案只在两行内重复文本 |
| 后端在详情里直接返回 `options: [{key,label}]` 归一结构 | 现网已返回 `optionsJson`，纯展示层可解析；改契约要连带改 DTO、教师页类型与镜像测试，收益为零 |
| 学生端与教师端各自在 SFC 内复制一份解析与模板 | 两处重复实现易漂移；跨角色复用统一落 `components/exam/` 与 `utils/` |
| 结果页题卡整块可折叠（默认收起选项） | 学生恰恰需要直接看到选项，折叠与本次目标相反 |
| 判断题也渲染选项列表 | 判断题答案已展示「正确 / 错误」，历史数据选项键为 `T` / `F`，与 A/B 语义不一致，强行渲染易误导 |
