## 1. 背景与问题

### 1.1 现象

学生「实验任务」页可见进行中的实验（如 `SAVED` 草稿、54% 进度），但「总览」页同时显示：

- 顶部摘要「0 待完成任务」
- 待办任务区空态
- 快捷入口「我的实验 · 当前关联 0」

### 1.2 根因（已核实）

V9 实验模块重构后，运行时实验数据写入 **新表**：

| 领域实体 | JPA `@Table` | 说明 |
|----------|--------------|------|
| `Lab` | `t_experiment` | 实验主表 |
| `LabSubmission` | `experiment_submission` | 实验提交 |

学生实验列表 `LabService.listStudentLabs()` 已走 JPA 新表；`AnalysisService` 仍用 JDBC 查 **遗留空表** `lab` / `lab_submission`。

**Flyway mem（`./mvnw test`）与路径 B 文件库对比**：

| 环境 | `lab` | `t_experiment`（教师 `t9001`） | 说明 |
|------|-------|-------------------------------|------|
| Flyway mem 干净种子 | 0 | 3（`1001`/`1002`/`1003`） | **单元测试以此为准** |
| 路径 B 文件库（联调） | 0 | 5+（含联调新增实验） | 仅用于 §8.3 人工验收 |

因此总览统计恒为 0，与实验列表页数据脱节。

### 1.3 设计结论（一句话）

在 `AnalysisService` 内将实验相关 JDBC SQL 全部切换到 `t_experiment` / `experiment_submission`，字段按 §3 映射；学生/教师总览、成绩完成率、业务名回查与实验/作业列表 API 口径一致。

## 2. 目标与非目标

### 2.1 目标

1. 学生总览 `pendingTasks`、`upcomingTasks`、快捷入口「我的实验」能反映真实待办实验。
2. 教师总览教学活动数、待批改实验数、近期实验待办能反映 `t_experiment` / `experiment_submission` 数据。
3. 学生成绩总览 `completionRate` 分母包含已发布实验（不再因查空表而为 0）。
4. `score_record.business_type = LAB` 且 `business_id = experiment_id` 时，业务名回查显示真实实验名。

### 2.2 非目标

- 不修改 `frontend/src/views/student/Dashboard.vue`。
- 不删除物理库遗留表 `lab` / `lab_submission`。
- 不改造 `PlagiarismService`（其仍引用 `lab` / `lab_submission`，属独立缺陷，另开任务）。
- 不回填 `score_record.business_id`（如种子 `-1` 等历史值）。
- 不重构 `AnalysisService` 为领域 Service 调用。
- 不改变待办排序规则（仍按 `dueAt` 升序，`nullsLast(naturalOrder())`，取前 5 条）。
- 不使考试 `totalItems` 完全复刻 `ExamService.listExams` 对 `CLOSED` 场次的展示规则（见决策 #12）。

## 3. 表与字段映射

### 3.1 实验主表

| 遗留 SQL（`lab l`） | 新 SQL（`t_experiment e`） |
|---------------------|----------------------------|
| `l.id` | `e.experiment_id` |
| `l.title` | `e.experiment_name` |
| `l.end_at` | `e.end_at` |
| `l.class_id` | `e.class_id` |
| `l.created_by` | `e.created_by` |
| `l.status` | `e.status` |

### 3.2 实验提交表

| 遗留 SQL（`lab_submission ls`） | 新 SQL（`experiment_submission es`） |
|--------------------------------|--------------------------------------|
| `ls.lab_id` | `es.experiment_id` |
| `ls.student_id` | `es.student_id` |
| `ls.submit_status` | `es.submit_status` |
| `ls.submitted_at` | `es.submitted_at` |
| `ls.id` | `es.id` |

### 3.3 JOIN 写法约定（实验域）

统一别名：`e` = `t_experiment`，`es` = `experiment_submission`，`cm` = `class_member`。

```sql
FROM t_experiment e
JOIN class_member cm ON cm.class_id = e.class_id
LEFT JOIN experiment_submission es
  ON es.experiment_id = e.experiment_id
 AND es.student_id = cm.student_user_id
```

### 3.4 考试域别名（避免与实验 `e` 冲突）

统一别名：`ex` = `exam`，`exs` = `exam_submission`。

## 6. 目标 SQL 片段（实现直接对照）

### 6.1 学生待完成实验数 `pendingLabCount`

```sql
SELECT COUNT(*)
FROM t_experiment e
JOIN class_member cm ON cm.class_id = e.class_id
LEFT JOIN experiment_submission es
  ON es.experiment_id = e.experiment_id
 AND es.student_id = cm.student_user_id
WHERE cm.student_user_id = ?
  AND e.status = 'PUBLISHED'
  AND (es.id IS NULL OR es.submit_status NOT IN ('SUBMITTED', 'GRADED'))
```

### 6.2 学生待办实验列表（`buildStudentUpcomingTasks` 实验段）

```sql
SELECT e.experiment_name AS title, e.end_at AS due_at
FROM t_experiment e
JOIN class_member cm ON cm.class_id = e.class_id
LEFT JOIN experiment_submission es
  ON es.experiment_id = e.experiment_id
 AND es.student_id = cm.student_user_id
WHERE cm.student_user_id = ?
  AND e.status = 'PUBLISHED'
  AND (es.id IS NULL OR es.submit_status NOT IN ('SUBMITTED', 'GRADED'))
```

组装：`studentTask("实验", title, dueAt, "/student/labs")`。

### 6.3 教师教学活动实验数

```sql
SELECT COUNT(*) FROM t_experiment WHERE created_by = ?
```

### 6.4 教师待批改实验

**计数（`pendingLab`）**：§4.4。

**近期列表（`buildTeacherRecentTasks` 实验段）**：

```sql
SELECT es.submitted_at AS event_time,
       e.experiment_name AS title,
       u.display_name AS actor
FROM experiment_submission es
JOIN t_experiment e ON es.experiment_id = e.experiment_id
JOIN sys_user u ON u.id = es.student_id
WHERE e.created_by = ?
  AND es.submit_status = 'SUBMITTED'
```

### 6.5 实验业务名回查

```sql
SELECT experiment_name FROM t_experiment WHERE experiment_id = ?
```

### 6.6 学生成绩完成率分母 `totalItems`

```sql
-- 实验
SELECT COUNT(*)
FROM t_experiment e
JOIN class_member cm ON cm.class_id = e.class_id
WHERE cm.student_user_id = ?
  AND e.status = 'PUBLISHED'

-- 作业
SELECT COUNT(*)
FROM homework h
JOIN class_member cm ON cm.class_id = h.class_id
WHERE cm.student_user_id = ?
  AND h.status = 'PUBLISHED'

-- 考试
SELECT COUNT(*)
FROM exam ex
JOIN class_member cm ON cm.class_id = ex.class_id
WHERE cm.student_user_id = ?
  AND ex.status = 'PUBLISHED'
```

三段求和为 `totalItems`；`completionRate = completedItems * 100.0 / totalItems`（`totalItems = 0` 时仍为 `0.0`）。

> **注（考试分母）**：学生 `ExamService.listExams` 还会展示「已 `CLOSED` 但学生已有提交」的场次；本期 `totalItems` **仅计 `PUBLISHED`**，与实验/作业口径统一，属已知简化，不纳入本期验收争议项。
