## 2. 背景与目标

PRD V1.4 已定：全站 17 处页面级返回按钮与全局可点击面包屑的父级段目标完全重复，一律删除；`< 900px` 面包屑从隐藏改为紧凑常显，为移动端深层页面保留唯一显式回退路径；删除必须连同薄壳面板解构与 composable 级联彻底清理。本方案给出唯一实现路径：逐文件删除锚点、死代码四件套、级联清理与 3 个 spec 改写的精确断言。

### 4.4 移动端面包屑紧凑常显（`layout/AppBreadcrumb.vue`）

将现有媒体查询块：

```css
@media (max-width: 899px) {
  .app-breadcrumb {
    display: none;
  }
}
```

整体替换为：

```css
@media (max-width: 899px) {
  .app-breadcrumb {
    height: auto;
    min-height: 34px;
    flex-wrap: wrap;
    padding: 4px 0;
    font-size: 11px;
    letter-spacing: 0.04em;
  }
}
```

基础块（`display: flex; flex: none; height: 34px; max-width: 1380px; margin: 0 auto`）与全部链接 / 分隔符 / `aria-current` 规则一字不动。模板与 `<script setup>` 零改动。紧凑态高度语义：短路径 34px 与桌面一致；长路径（如教师四段面包屑在 375px）换行后增高，`min-height` 保底、页面自然滚动，无溢出遮挡。
