### 3.4 `Range/206` 协议层（只落 `StudentContentController`）

```java
private static final Pattern SINGLE_RANGE = Pattern.compile("^bytes=(\\d+)-(\\d*)$");

@GetMapping("/coursewares/{coursewareId}/assets/{assetId}")
public ResponseEntity<byte[]> readAsset(
        @PathVariable Long coursewareId, @PathVariable Long assetId,
        @RequestHeader(value = "Range", required = false) String rangeHeader) {
    CurrentUser currentUser = SecurityUtils.currentUser();
    DownloadedAsset asset = studentContentService.readAsset(currentUser, coursewareId, assetId);
    byte[] bytes = asset.bytes();
    String mimeValue = asset.mime() == null || asset.mime().isBlank()
            ? MediaType.APPLICATION_OCTET_STREAM_VALUE : asset.mime();
    MediaType mime = MediaType.parseMediaType(mimeValue);   // 与 TeacherContentController:76-80 一致
    Matcher matcher = SINGLE_RANGE.matcher(rangeHeader == null ? "" : rangeHeader.trim());
    if (!matcher.matches()) {
        return fullResponse(bytes, mime, asset.fileName());
    }
    try {
        long start = Long.parseLong(matcher.group(1));
        String endGroup = matcher.group(2);
        long end = endGroup.isEmpty() ? bytes.length - 1 : Long.parseLong(endGroup);
        if (start >= bytes.length || end >= bytes.length || start > end) {
            return fullResponse(bytes, mime, asset.fileName());
        }
        byte[] part = Arrays.copyOfRange(bytes, (int) start, (int) end + 1);
        return ResponseEntity.status(HttpStatus.PARTIAL_CONTENT)
                .contentType(mime)
                .header("Content-Range", "bytes " + start + "-" + end + "/" + bytes.length)
                .header("Accept-Ranges", "bytes")
                .header("Content-Disposition", "inline; filename=\"" + asset.fileName() + "\"")
                .body(part);
    } catch (NumberFormatException ex) {
        return fullResponse(bytes, mime, asset.fileName());
    }
}
```

- `fullResponse` 签名写死为 `private ResponseEntity<byte[]> fullResponse(byte[] bytes, MediaType mime, String fileName)`，返回 `200` + `Accept-Ranges: bytes` + `Content-Disposition: inline` + `byte[]` 全量；**不新增 `@ControllerAdvice`、不改 `GlobalExceptionHandler`、不新增状态码 / 错误码**。**实施期现网核对**：若返回 `Resource`（`ByteArrayResource`），Spring MVC 会对 `200` 的 Resource 响应自行按请求 `Range` 截取，实测多区间 `bytes=0-1,3-4` 被框架转成 `206 multipart/byteranges`，「非法 / 多区间 → `200` 全量」口径失效；故响应体必须是 `byte[]`，Range 判定只发生在本 Controller。阶段 3 两个 `readAsset` 仍为 `ResponseEntity<ByteArrayResource>` 且不带 Range 处理，一字不改。
- 含逗号多区间（正则不匹配）、非法格式、数字溢出（`NumberFormatException`）、越界（`start >= total` / `end >= total` / `start > end`）一律走 `fullResponse`（`200` 全量）；错误码一律由 Service 在读取前判定，Controller 不产生新 `4xx`。
- 前端播放器本期不发送 `Range` 头（TD18 走 axios 全量 blob），`206` 由 `CoursewareAssetRangeTests` 用 MockMvc `header("Range", "bytes=0-3")` 验证。
