## 2. 已定决策清单

| 编号 | 决策点 | 唯一结论 |
|---|---|---|
| TD1 | 填空题解析入口 | 在 `GradingAdapter` 新增私有 `List<String> parseFillBlankAnswers(String answerJson)`；`resolveStudentAnswer` 的 `FILL_BLANK` 分支先调用它，返回非空列表即直接使用 |
| TD2 | 填空对象形态识别 | 仅当 JSON 解析结果为 `Map`、`kind` 字符串 `trim()` 后忽略大小写等于 `fill`、且 `blanks` 为 `List` 时生效；否则返回空列表 |
| TD3 | 空位提取规则 | 逐项要求 `blanks` 元素为 `Map`；`index` 用现有 `asInt` 解析（失败得 0），`index <= 0` 跳过；`answer` 为 `null` 写空串，否则 `String.valueOf`；按 `index` 升序稳定排序；**保留空串**；**不按 index 数值补空洞**；重复 `index` 保留两条并按出现顺序稳定排序 |
| TD4 | 填空回退链 | `parseFillBlankAnswers` 返回空列表时依次回退 `parseAnswerList(answerJson)`（旧数组/`selectedOptions` 形态）与 `answerText`（纯文本）；`parseFillBlankAnswers` 返回单元素空串列表时不回退 |
| TD5 | 填空不改动面 | `FillBlankScoringStrategy`、`normalizeAnswerJson`、前端提交结构、题库答案结构均不改 |
| TD6 | 学生看板资料过滤 | `getStudentDashboard` 的 `materialCount` 与 `recentMaterials` 两条 SQL 均追加 `AND school_id = ?`，参数为 `student.schoolId()`；`schoolId == null` 时不执行 SQL，直接返回 `0` 与 `List.of()` |
| TD7 | 学生看板查询形态 | `materialCount` 复用现有 `count(sql, args...)`；`recentMaterials` 改用 `jdbcTemplate.query(sql, rowMapper, schoolId)` 的参数化重载，SQL 与行映射字段不变 |
| TD8 | 考试未开始判定 | `getExamDetail` 在学生身份与班级成员校验之后、题目快照组装之前计算：`boolean notStarted = currentUser.role() == UserRole.STUDENT && exam.getStartAt() != null && OffsetDateTime.now().isBefore(exam.getStartAt())` |
| TD9 | 考试未开始短路返回 | `notStarted == true` 时只返回 `id/title/description/classId/className/startAt/endAt/durationMinutes/status/scoreVisibilityMode/shuffleQuestions`，追加 `questions = List.of()` 与 `notStarted = true`，**不**查询 `exam_question`、**不**查询 `exam_submission`、**不**回填任何提交与判分字段 |
| TD10 | 考试详情基础视图复用 | 抽取私有 `Map<String, Object> buildExamBaseView(Exam exam)` 生成上述 11 个基础字段；未开始短路与正常路径共用，避免字段漂移 |
| TD11 | 考试详情正常路径 | `notStarted == false` 时完全沿用现有逻辑：题目组装、教师答案与解析、学生提交回填与草稿答案回填；`notStarted` 字段只在为 `true` 时输出，**不输出 `false`** |
| TD12 | 图片路径规范化 | `LabAnswerImageSupport.normalizeRelativePath` 在 `replace('\\','/').trim()` 后按 `/` 拆分，任一段等于 `..` 立即抛 `BusinessException(40000, "图片路径不合法")`；空路径保持返回空串，由后续正则拒绝 |
| TD13 | 图片存储边界 | 新增常量 `LAB_ANSWER_ROOT = "lab-answers"`；所有落盘校验统一为 `Path root = storageRoot.resolve(LAB_ANSWER_ROOT).normalize()` 且 `target.startsWith(root)` |
| TD14 | 图片路径正则 | 两个正则只在 `LabAnswerImageSupport` 内定义：`LAB_ANSWER_PATH_PATTERN = ^lab-answers/\d{4}-\d{2}-\d{2}/.+`（预览与历史兼容）；`LAB_ANSWER_STUDENT_PATH_PATTERN = ^lab-answers/\d{4}-\d{2}-\d{2}/(\d+)/.+`（保存与预览归属校验）。新增静态 `boolean matchesAnswerPath(String path)` 与 `void assertStudentSegmentMatches(String path, CurrentUser currentUser, Long ownerStudentId)`，`LabService` 与测试一律调用静态方法，不内联 `String.matches` 复制正则 |

```java
private List<String> parseFillBlankAnswers(String answerJson) {
    Object parsed = readJsonObject(answerJson);
    if (!(parsed instanceof Map<?, ?> root)) {
        return List.of();
    }
    Object kind = root.get("kind");
    if (kind == null || !"fill".equalsIgnoreCase(String.valueOf(kind).trim())) {
        return List.of();
    }
    if (!(root.get("blanks") instanceof List<?> blanks)) {
        return List.of();
    }
    List<Map.Entry<Integer, String>> pairs = new java.util.ArrayList<>();
    for (Object item : blanks) {
        if (!(item instanceof Map<?, ?> blank)) {
            continue;
        }
        int index = asInt(blank.get("index"));
        if (index <= 0) {
            continue;
        }
        Object value = blank.get("answer");
        pairs.add(Map.entry(index, value == null ? "" : String.valueOf(value)));
    }
    if (pairs.isEmpty()) {
        return List.of();
    }
    pairs.sort(Map.Entry.comparingByKey());
    return pairs.stream().map(Map.Entry::getValue).toList();
}
```

#### 4.5.3 草稿服务

```java
@Transactional
public Map<String, Object> saveHomeworkDraft(CurrentUser currentUser, Long homeworkId,
                                             HomeworkRequests.SubmitHomeworkRequest request) {
    requireStudent(currentUser);
    Homework homework = accessiblePublishedHomework(currentUser, homeworkId);
    if (homework.getStatus() == ActivityStatus.CLOSED) {
        throw new BusinessException(40000, "作业已关闭，不能保存草稿");
    }
    if (homework.getStartAt() != null && OffsetDateTime.now().isBefore(homework.getStartAt())) {
        throw new BusinessException(40000, "作业尚未开始");
    }
    if (homework.getDueAt() != null && OffsetDateTime.now().isAfter(homework.getDueAt())) {
        throw new BusinessException(40000, "作业已截止，不能保存草稿");
    }
    SubmissionStatus claimStatus = homeworkSubmissionRepository
            .findByHomeworkIdAndStudentId(homeworkId, currentUser.id())
            .map(HomeworkSubmission::getSubmitStatus)
            .orElse(null);
    if (claimStatus == null) {
        try {
            homeworkSubmissionClaimService.claim(homeworkId, currentUser.id());
        } catch (DataIntegrityViolationException ex) {
            // 并发首存：下一句锁内重读
        }
    }
    HomeworkSubmission submission = homeworkSubmissionRepository
            .findByHomeworkIdAndStudentIdForUpdate(homeworkId, currentUser.id())
            .orElseThrow(() -> new BusinessException(50000, "作业草稿创建失败，请重试"));
    if (submission.getSubmitStatus() == SubmissionStatus.SUBMITTED
            || submission.getSubmitStatus() == SubmissionStatus.GRADED) {
        throw new BusinessException(40000, "已提交作业不可修改草稿");
    }
    submission.setHomeworkId(homeworkId);
    submission.setStudentId(currentUser.id());
    submission.setSubmitStatus(SubmissionStatus.SAVED);
    submission.setAnswerText(request.answerText());
    submission.setAnswerFilePath(blankToNull(request.resolvedAttachmentPath()));
    submission.setTotalScore(null);
    submission.setTeacherComment(null);
    submission.setGradedAt(null);
    HomeworkSubmission saved = homeworkSubmissionRepository.saveAndFlush(submission);
    if (request.questionBased()) {
        applyDraftAnswers(saved, request.answers());
        saved = homeworkSubmissionRepository.saveAndFlush(saved);
    }
    OffsetDateTime savedAt = Objects.requireNonNullElse(saved.getUpdatedAt(), OffsetDateTime.now());
    return Map.of("submissionId", saved.getId(), "status", "SAVED", "savedAt", savedAt.toString());
}
```

`applyDraftAnswers` 只落作答，不复用 `applyQuestionAnswers`：

```java
private void applyDraftAnswers(HomeworkSubmission submission,
                               List<HomeworkRequests.SubmitHomeworkAnswerItem> items) {
    List<HomeworkQuestion> questions =
            homeworkQuestionRepository.findByHomeworkIdOrderBySortOrder(submission.getHomeworkId());
    Map<Long, HomeworkQuestion> questionMap = questions.stream()
            .collect(Collectors.toMap(HomeworkQuestion::getId, item -> item));
    for (HomeworkRequests.SubmitHomeworkAnswerItem item : items) {
        HomeworkQuestion question = questionMap.get(item.homeworkQuestionId());
        if (question == null) {
            throw new BusinessException(40000, "提交题目不存在");
        }
        HomeworkAnswer answer = homeworkAnswerRepository
                .findByHomeworkSubmissionIdAndHomeworkQuestionId(submission.getId(), question.getId())
                .orElseGet(HomeworkAnswer::new);
        answer.setHomeworkSubmissionId(submission.getId());
        answer.setHomeworkQuestionId(question.getId());
        answer.setQuestionId(question.getQuestionId());
        answer.setAnswerText(blankToNull(item.answerText()));
        answer.setAnswerJson(resolveAnswerJson(item));
        answer.setScore(null);
        answer.setAutoScore(null);
        answer.setSuggestedScore(null);
        answer.setJudgeDetail(null);
        answer.setTeacherComment(null);
        answer.setScoreSource("TEACHER");
        answer.setAcceptedAutoScore(false);
        homeworkAnswerRepository.save(answer);
    }
}
```

### 4.6 事务与并发

- `saveBlankAcceptedAnswers`、`gradeReport`、`confirmAnswer`、`saveHomeworkDraft` 均保持方法级 `@Transactional`，写分/写记录都在提交行悲观写锁之后。
- `ScoreRecordWriter.remove` 与调用方同事务，降级回滚时删除一并回滚。
- 作业状态迁移的存在性判定不加行锁，与并发首存 `SAVED` 草稿的极小竞态按 PRD §14.1 接受，不新增锁方法。

## 10. 风险与兼容

1. N1 修复只影响后续评分；历史错误分数不自动重算，需教师重新批改。
2. N3 上线后开始时间前无法预览题目属预期，需提前告知教师与学生。
3. N4 新旧上传路径并存，预览必须保留旧式兼容，否则存量报告图片不可见。
4. N5 冻结只覆盖“学生已可见”的提交；`AFTER_TEACHER_CONFIRM` 下未批改完成的提交仍按自动分刷新。
5. N8 收紧后历史 `CLOSED` 作业不能直接发布，教师需新建作业，后续迭代提供重新开放。
6. N9 不提供“撤回发布”；`IMMEDIATE` / `AFTER_TEACHER_CONFIRM` 下仍允许纠错。
7. N10 草稿写请求频率由 800ms 防抖与离开前 flush 控制；离线兜底列入后续迭代。
8. 状态迁移的存在性校验未加作业行锁，与并发首存草稿的极小竞态本期接受。
9. `scoreSource` 因列 `NOT NULL` 在草稿中写 `"TEACHER"`，其余评分字段置 `null`；这是本方案对 PRD “评分字段置空”的可执行化口径。
10. 创建接口不再接受显式 `status=CLOSED`；如有历史调用方直接建已关闭作业，需改为先建 `DRAFT/PUBLISHED` 再关闭。
