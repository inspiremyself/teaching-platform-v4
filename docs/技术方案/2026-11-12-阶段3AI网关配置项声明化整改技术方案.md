## 3. 唯一实现路径

### 3.1 配置声明（`application.yml`）

在 `app.audit-log` 段（`application.yml:37-39`）之后、`:41` 注释行与 `:42` 的 `lab:` 顶层块之前，追加 `app` 块内的 `courseware` 子块；`app` 顶层键不重复声明，`lab:` 及其注释位置不变：

```yaml
  courseware:
    ai:
      # 四项值只由环境变量注入；仓库内不提供可用 api-key
      base-url: ${COURSEWARE_AI_BASE_URL:}
      api-key: ${COURSEWARE_AI_API_KEY:}
      model: ${COURSEWARE_AI_MODEL:}
      timeout-seconds: ${COURSEWARE_AI_TIMEOUT_SECONDS:120}
```

插入后 `application.yml` 的 `spring.servlet.multipart.max-file-size: 50MB` / `max-request-size: 100MB`（`:8-9`）保持不动；不新增 Flyway 占位符、不改 `ddl-auto`、不改 `server.port`、不改 `app.jwt-secret`。

### 3.2 配置对象（`content/config/`）

新建 `content/config/` 子包（业务域内二级子包，不新建顶层域、不下沉到 `common/config/`；依据 `backend-package-layout.mdc` §3「新增能力优先落在既有业务域」与 §4 单向依赖）：

| 类 | 注解 | 内容 |
|---|---|---|
| `CoursewareAiProperties` | `@ConfigurationProperties(prefix = "app.courseware.ai")` | 普通 Java 类；`private String baseUrl = "";`、`private String apiKey = "";`、`private String model = "";`、`private int timeoutSeconds = 120;`；public 方法唯一为 `getBaseUrl()` / `setBaseUrl(String)` / `getApiKey()` / `setApiKey(String)` / `getModel()` / `setModel(String)` / `getTimeoutSeconds()` / `setTimeoutSeconds(int)`（JavaBean 绑定，方法名不得改写）；中文 JavaDoc 写明「值由 `application.yml` 的 `${COURSEWARE_AI_*:}` 占位符注入，仓库内不提供密钥」。**无 Lombok、无 record、无 `@ConstructorBinding`、无 `@Validated`、无 `@NotBlank`**（空串是合法「未配置」态） |
| `CoursewareAiConfig` | `@Configuration` + `@EnableConfigurationProperties(CoursewareAiProperties.class)` | 空类体、无字段、无构造器；只承担注册，与 `BehaviorConfig` / `AuditLogConfig` 同构；类级中文 JavaDoc 写明「AI 网关配置对象注册入口」（`backend-code-style.mdc` §1.5，现网 `BehaviorConfig.java:6-11` 同构） |

`timeout-seconds` 的 `120` 在 `application.yml` 的 `${COURSEWARE_AI_TIMEOUT_SECONDS:120}` 占位符与 Java 字段初值中同值，形态与现网 `BehaviorProperties` 的「Java 字段给默认值 + `application.yml` 显式声明」同构（现网 `lab.behavior.*` 在 yml 里是字面量常量，本方案这里是环境变量占位符）；`CoursewareAiGateway` 的 `<= 0 → 120` 作为非法输入兜底继续保留。三者不构成状态真相源，唯一运行取值来自 Spring 绑定结果。

`content/config/` 是业务域内二级子包：不放入 `common/config/`（业务域专有配置不下沉通用层）、不放入 `content/service/`（配置类不属业务逻辑层）、不新建顶层域；依赖方向 `content/ → common/` 单向，符合 `backend-package-layout.mdc` §3 / §4。

### 3.3 网关改造（`CoursewareAiGateway.java`）

- 删除 `import org.springframework.beans.factory.annotation.Value;`，新增 `import com.opencode.teachingplatform.content.config.CoursewareAiProperties;`。
- 构造器签名唯一为 `public CoursewareAiGateway(ObjectMapper objectMapper, CoursewareAiProperties properties)`；字段 `objectMapper` / `baseUrl` / `apiKey` / `model` / `timeoutSeconds` 全部保留 `private final`，仍用显式 public 构造器注入（`backend-code-style.mdc` §4）。
- 构造器体写死：

```java
this.objectMapper = objectMapper;
this.baseUrl = properties.getBaseUrl() == null ? "" : properties.getBaseUrl().trim();
this.apiKey = properties.getApiKey() == null ? "" : properties.getApiKey().trim();
this.model = properties.getModel() == null ? "" : properties.getModel().trim();
this.timeoutSeconds = properties.getTimeoutSeconds() <= 0 ? 120 : properties.getTimeoutSeconds();
```

- 类注释 `:21-22` 改为「四项参数绑定自 `app.courseware.ai.*` 配置键，值经 `${COURSEWARE_AI_*:}` 占位符由环境变量注入；缺少 base-url / api-key / model 时 `isConfigured()` 为 false，AI 生成入口直接拒绝并保证不落库」。
- `isConfigured()` / `complete(...)` / `requestBody(...)` / `trimTrailingSlash(...)` 方法体与 `CONNECT_TIMEOUT_SECONDS` 常量**一字不改**。
