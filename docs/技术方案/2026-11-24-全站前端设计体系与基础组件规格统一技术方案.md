## 3. 架构设计

### 3.1 分层与依赖方向

```text
views/**（L3：只写页面编排，引用 token / 骨架类 / ui 组件）
   │ import
   ▼
components/ui/*（L2：结构 + 语义类 + 插槽，无 style、无业务）
   │ class 来自
   ▼
assets/layout.css（L1：骨架类与共享展示类，值全部取 var(--...)）
   │ var() 来自
   ▼
assets/tokens.css（L0：唯一变量定义 + Element Plus 映射）
```

- `global.css` 保留 Element Plus 组件覆盖、字体声明、`.workbench-*`、`.kpi-card`、`.material-symbols-outlined`、滚动条；不再定义骨架类与 `:root` 变量。
- `layout/index.vue` 是角色主题注入点，只把 `--primary-*` 指向品牌 token，不新增其它变量。

### 3.2 `tokens.css` 变量清单（写死）
