## 3. `frontend/src/utils/format.ts`

### 3.1 导出签名

```ts
export interface DateFormatOptions {
  fallback?: string
}

export interface ScoreFormatOptions {
  digits?: number
  stripTrailingZero?: boolean
  fallback?: string
}

export function formatDateTime(value: string | null | undefined, options?: DateFormatOptions): string

export function formatShortDateTime(value: string | null | undefined, options?: DateFormatOptions): string

export function formatScore(value: number | null | undefined, options?: ScoreFormatOptions): string
```

### 3.2 行为规格

1. `formatDateTime`：空值或 `Number.isNaN(new Date(value).getTime())` 时返回 `options.fallback ?? '-'`；否则返回 `` `${year}-${pad2(month)}-${pad2(date)} ${pad2(hours)}:${pad2(minutes)}` ``。
2. `formatShortDateTime`：同样的空值/非法值分支；合法时返回 `` `${month}/${date} ${pad2(hours)}:${pad2(minutes)}` ``，月与日不补零，时与分补零。
3. `formatScore`：`typeof value !== 'number' || !Number.isFinite(value)` 时返回 `options.fallback ?? '-'`；否则先 `value.toFixed(options.digits ?? 1)`，`stripTrailingZero === true` 时再 `.replace(/\.0$/, '')`。
4. 三个函数均为纯函数，不读写全局状态、不抛异常、不处理时区字符串拼接之外的事情。
5. 内部只允许一个私有 `pad2(value: number): string` 与一个私有 `toValidDate(value): Date | null`；不导出。

### 3.3 时区与非法值口径

- 带偏移的 ISO 串（如 `2026-11-25T10:00:00+08:00`）按浏览器本地时区换算后渲染；服务端与用户同为 `+08:00` 时与现网 `slice` 输出逐字符一致。
- 无偏移串（如 `2026-11-25T10:00:00`）由 `new Date` 按本地时间解释，与现网 `slice` 的文本一致。
- 非法串由「原样回显」改为 fallback，属 PRD FR-1.2 已登记的纠偏，不作为行为回归。
- 输入契约为后端 ISO-8601 日期时间串（带或不带偏移）；纯日期串（`YYYY-MM-DD`）不在契约内，若出现会被补出 `00:00`/`08:00`，实现自查时须确认本次迁移的字段均含时间部分。

| 调用点 | 函数 | options |
|---|---|---|
| `useScores.ts` 的 `formatDate` 迁移点 | `formatDateTime` | 缺省（`'-'`） |
| `useHomeworkDetail.ts`、`useHomeworks.ts`、`useStudentLabSteps.ts`、`student/Labs.vue`、`student/Homeworks.vue`、`LabReportDetail.vue`、`LabListPanel.vue` | `formatDateTime` | 缺省（`'-'`） |

### 3.5 options 传递规则（写死）

1. composable / 组件的脚本内部：调用工具时显式写第二参数；凡现网空值兜底不是 `'-'` 的调用点，必须写对应 fallback（`'未设置'` / `'时间待定'` / `'时间未记录'`）。
2. 组件模板：不新增同名或近名本地包装函数（与 T5、PRD FR-1.7 一致）；在模板调用点直接写第二参数，例如 `{{ formatDateTime(row.startAt, { fallback: '未设置' }) }}`、`{{ formatShortDateTime(task.dueAt, { fallback: '时间待定' }) }}`。仅当现网兜底为 `'-'` 时可省略。
3. `formatWindow` / `submissionTimeLabel` 这类保留的业务函数在函数体内显式传参；目标字段选择（如 `row.submittedAt || row.startedAt`）与空判断留在业务函数内。仅做单位拼接、以业务语义命名的单行函数同样允许保留（如 `ScoresPanel.vue` 的 `scoreText`），但不得定义与工具同名或仅转调的 `formatXxx`。
4. 禁止用 `bind`、模块级常量或可变默认值改写 fallback。

  EXAM_SUBMISSION_STATUS,

export type StatusScene = 'teacher' | 'student'
export type StatusTone = 'neutral' | 'success' | 'info' | 'warning' | 'danger'
export type ElTagType = 'primary' | 'success' | 'info' | 'warning' | 'danger'

export interface StatusPresentation {
  label: string
  tone: StatusTone
}

export interface StatusPresentationInput {
  module: StatusModule
  kind: StatusKind
  scene: StatusScene
  status: string
  /** 仅用于保留现网「未知非空状态」兜底；未提供时返回原值 */

### 4.4 查询与兜底

1. 先取 `OVERRIDES[`${module}:${kind}:${scene}`]?.[status]`，命中即返回。
2. 再取 `BASE[`${kind}:${scene}`]?.[status]`，命中即返回。
3. 都未命中时：`unknownLabel` 有值返回 `{ label: unknownLabel, tone: 'neutral' }`；否则返回 `{ label: status, tone: 'neutral' }`。不回显「未知」，不抛异常。
4. 表键使用 `ACTIVITY_STATUS` / `SUBMISSION_STATUS` / `EXAM_SUBMISSION_STATUS` 常量，禁止手写状态字符串。

### 4.5 `toElTagType`

1. `tone === 'neutral'` 返回 `neutralAs`，其余五值原样返回，返回类型收窄为 `ElTagType`。
2. 该函数只服务原生 `el-tag :type`；`AppStatusTag` 宿主直接传 `tone`，不调用它。
3. `neutralAs` 由调用文件按现网未知状态默认值写死：`StudentLabSubmissions` / `LabItemAnswersWall` / `LabSubmissionOverview` 传 `'info'`；`student/Homeworks` 传 `'primary'`。禁止在调用点再写 `if` 判断。
