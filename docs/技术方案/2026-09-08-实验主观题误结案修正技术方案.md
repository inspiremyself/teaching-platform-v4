## 2. 背景与诉求

### 2.1 现象

教师配置台题型为「简答题」的实验，学生提交后批改队列出现：**「已批改」、总分 0、提交时间与批改时间相同**。产品侧误以为「简答题也被自动判分」。

### 2.2 根因（对照现网代码）

1. 前端落库题型为 **`SHORT_ANSWER`**；`LabScoringSupport.resolveQuestionType` **未识别** → `unsupported question type` / `ScoreSource.TEACHER`。
2. `saveAnswer` / `uploadAnswerImage` 在 `score == null` 时写入 **`0D`**，草稿期已有假分。
3. `applyScoringResult` 对引擎 `TEACHER` **不改写**已有 `score` → 提交后假 `0` 残留。
4. `refreshSubmissionAfterScoring` 将「每题 `score != null`」视为已评完 → 误升 **`GRADED`**。

代码题（`CODE`）已映射为 `SUBJECTIVE`，正常路径应为 `SUGGESTED` + `score=null` + `SUBMITTED`；与简答题一并验收。假 `0` 对任何「引擎返回 TEACHER」路径均危险，与映射一并根治。

### 2.3 设计结论（一句话）

识别实验契约 **`SHORT_ANSWER`** 为主观题，草稿不预写 0 分，非 AUTO 回填一律清空 `score`，新链路主观提交停在 `SUBMITTED`；旧脏数据不迁；**不为题库 `SHORT` 别名加实验兼容**。

## 3. 目标与非目标

### 3.1 目标

1. 纯主观实验（`SHORT_ANSWER` / `CODE` / `TEXT` / `SUBJECTIVE` 及其混合）：`submitLab` 后 **`SUBMITTED`**。
2. 主观题步骤：可有 `suggestedScore` / `autoJudgeDetail` / `scoreSource=SUGGESTED`；**`score` 为 `null`**。
3. 普通草稿保存、上传答题图：**不**产生最终 `score`。
4. 客观题自动判分与填空重判语义保持现网正确行为。

### 3.2 非目标

- 不批量修复历史误 `GRADED`、不写数据修复脚本。
- 不把主观题关键词命中自动写成最终分。
- 不改教师 `gradeReport` / `confirmStepScore` / 打回 API。
- 不改前端题型枚举展示、不改学生作答 UI。
- **不修改、不删除** `LabAutoGradingService.java`。
- 不要求 `applyStep` 双写 `scoringConfigJson`。
- **不改**两个 `refresh*` 方法体。
- **不**在 `LabScoringSupport` 中映射题库域 **`SHORT`**（与作业 `GradingAdapter` 的 `SHORT` 处理无关，实验契约以 `SHORT_ANSWER` 为准）。

## 4. 行为规格

### 4.1 题型 → 引擎类型

| 落库 / 快照 `questionType`（规范化大写） | `QuestionType` |
|------------------------------------------|----------------|
| `SINGLE_CHOICE` | `SINGLE_CHOICE` |
| `MULTIPLE_CHOICE` | `MULTIPLE_CHOICE` |
| `TRUE_FALSE` | `TRUE_FALSE` |
| `FILL_BLANK` | `FILL_BLANK` |
| `TEXT` / `SUBJECTIVE` / `CODE` / **`SHORT_ANSWER`** | `SUBJECTIVE` |
| `SHORT` 及其他 | `null` → 现有「unsupported」→ `applyScoringResult` 后 `score=null`（`SHORT` **故意不映射**） |

### 4.2 `applyScoringResult`（写死）

```text
写入 autoScore / suggestedScore / scoreSource / autoJudgeDetail
（RECOMMENDED → 库内 scoreSource 字符串 "SUGGESTED"；其余用 ScoreSource.name()）

若 scoreSource ∈ {AUTO, AUTO_ACCEPTED}:
    score = result.finalScore()   // 可为 0
否则:
    score = null
```

禁止「`TEACHER` 时保留原 score」。

### 4.3 提交后状态（依赖现有 `refreshSubmissionAfterScoring`，方法体不改）

| 场景 | 答案 `score` | `submitStatus` |
|------|--------------|----------------|
| 全主观且均已作答 | 全 `null` | **`SUBMITTED`**（`totalScore` 可为 `0D`） |
| 全客观且均可 AUTO | 全有分（含 0） | 可 **`GRADED`** |
| 客观 + 主观混合 | 客观有分、主观 `null` | **`SUBMITTED`** |
| 仅 `saveAnswer`（未提交、未重判） | `null` | **`SAVED`** |
| `SAVED` 草稿被填空重判命中 | 该步可有 `AUTO` 分 | **仍 `SAVED`**（现网；本期不改） |

### 4.4 草稿保存

- `saveAnswer` / `uploadAnswerImage`：只更新作答内容；**删除**预写 `0D`。
- 新建 `LabStepAnswer`：`score=null`；实体默认 `scoreSource="TEACHER"` **保持**（列 `NOT NULL`）。
- `SAVED` 下若已有分（填空重判 `AUTO`）：保存时**不**主动清空；随后 `submitLab` 再走 `applyScoringResult`。

## 7. 验收标准

### 7.1 自动化（必做）

测试种子对齐现网：`applyStep` 只落 `answer_config_json`、`scoring_config_json` 为空。使用六参 `seedStep`，**禁止**五参重载；题型字符串必须为 **`SHORT_ANSWER`**（禁止用 `SHORT` / `TEXT` 代替本缺陷回归）：

```text
seedStep(labId, 1, "SHORT_ANSWER",
         "{\"keywords\":[{\"term\":\"<命中词>\",\"weight\":10}]}",
         "{}",
         <stepScore>)
```

1. **`submitShortAnswerLabStaysSubmittedWithSuggestedScoreOnly`**  
   - 上式种子；学生答案命中关键词  
   - `saveAnswer` 后：`score == null`  
   - `submitLab` 后：`scoreSource=SUGGESTED`，`suggestedScore` 等于权重和（本例 `10`），`autoScore==null`，`score==null`，`submitStatus=SUBMITTED`，`gradedAt==null`，无对应 `ScoreRecord`；`submission.totalScore` 为 `0D` 可接受  

2. **`submitShortAnswerLabDoesNotAutoGradeWhenKeywordsMiss`**  
   - 同上配置；学生答案**不**含关键词  
   - `submitLab` 后：`scoreSource=SUGGESTED`，`suggestedScore=0D`，`autoScore==null`，`score==null`，`submitStatus=SUBMITTED`，`gradedAt==null`，无对应 `ScoreRecord`，不得 `GRADED`  

3. 既有 **`submitLabTreatsCodeStepAsSubjectiveRecommendation`**、**`suggestedLabScoreShouldRemainHiddenAndSkipScoreRecordBeforeTeacherConfirmation`**：**继续通过**  

4. **`saveBlankAcceptedAnswersRegradesCurrentLabItemIncludingSavedSubmissionsWithoutPromotingDraftStatus`**：`savedAnswerBefore.getScore()` 期望由 `0D` 改为 **`null`**；其余断言保持  

5. 合法 AUTO 得 0（如 `saveBlankAcceptedAnswersShouldNotBroadcastAcceptedWholeAnswerAcrossBlankSlots`）：**保持** `score==0` 且可 `GRADED`——与草稿假 0 区分  

### 7.2 手工（路径 B）

1. 仅简答题（`SHORT_ANSWER`）实验 → 学生提交 → 队列 **已提交**（非已批改）。  
2. 报告详情：建议评分 / 待确认，非系统终评 0 分结案。  
3. 教师确认或整份批改后可升 `GRADED`。  
4. 旧误结案：打回后重提，走新链路。
