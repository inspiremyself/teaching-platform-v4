### 3.2 门禁断言 #15 的精确口径

- 读取 `tokens.css`，用 `/--font-size-(xs|sm|base|md|lg|xl|2xl|3xl|4xl|5xl|6xl):\s*(\d+)px/g` 收集 11 个值，按档位顺序 `toEqual(FONT_SIZE_LADDER)`。
- 对 TD4 的 6 个 `--el-font-size-*`，逐项断言右值等于 TD4 写死的 `var(--font-size-*)`；对 TD6 的 3 个 `--el-component-size*`，逐项断言右值等于 TD6 写死的 `var(--control-height-*)`。
- 读取 `global.css`，按 §3.3 逐行断言：选择器对应的规则块内含指定自定义属性，且右值等于指定 `var()`；`.el-input-tag` 三选择器合并规则计一条。
- 不新增基线字段，不改写 `designTokenBaseline.json`。

### 3.3 EP 组件类覆盖块的一一对应（TD5 展开）

下表每行在 `global.css` 写成一条独立规则，选择器与 EP 定义选择器同名且加载在后，右值全部以 `var(` 开头：

| 选择器 | 自定义属性 | 右值 |
|---|---|---|
| `.el-tag` | `--el-tag-font-size` | `var(--el-font-size-sm)` |
| `.el-checkbox` | `--el-checkbox-font-size` | `var(--el-font-size-base)` |
| `.el-pagination` | `--el-pagination-font-size` | `var(--el-font-size-base)` |
| `.el-select` | `--el-select-input-font-size` | `var(--el-font-size-base)` |
| `.el-dialog` | `--el-dialog-content-font-size` | `var(--el-font-size-base)` |
| `.el-collapse` | `--el-collapse-header-font-size` | `var(--el-font-size-base)` |
| `.el-collapse` | `--el-collapse-content-font-size` | `var(--el-font-size-base)` |
| `.el-alert` | `--el-alert-title-font-size` | `var(--el-font-size-base)` |

`.el-input-tag` 必须同时覆盖三个选择器：EP 在 `--large` / `--small` 上定义了更高特异性的 14px / 12px，只写基础类会被变体遮蔽。

## 8. 已否决方案

| 否决项 | 原因 |
|---|---|
| 保守档（正文 14px、标题不动） | 用户已明确选择激进档；小字占比仍高，达不到可读性目标 |
| 在 `views/**` 536 处逐条改 `font-size` 字面量 | 违反 token 单一来源与门禁 #9，维护成本高 |
| 用 `html { font-size: 112.5% }` 缩放 | px token 不受 root 字号影响，无法覆盖现网 |
| 给 `body` 加 CSS `zoom` | 破坏固定定位与滚动容器，且无法分档建立层级 |
| 放大 Material Symbols 图标字号 | PRD D17 明确 18 / 24 固定豁免 |
