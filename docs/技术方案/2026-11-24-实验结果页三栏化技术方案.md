**取数与首屏选中**：

```ts
const labId = computed(() => Number(route.params.labId))
const rawRows = ref<LabReportItem[]>([])

const loadQueue = async (): Promise<LabReportItem[]> => {
  const all = await listTeacherLabReportQueue()
  const filtered = all.filter(row => row.labId === labId.value)
  const sorted = [...filtered].sort((a, b) => {
    const c = (a.className || String(a.classId ?? '')).localeCompare(b.className || String(b.classId ?? ''), 'zh-CN')
    return c !== 0 ? c : (a.studentNo || a.studentUsername || a.studentName || String(a.id))
      .localeCompare(b.studentNo || b.studentUsername || b.studentName || String(b.id), 'zh-CN', { numeric: true })
  })
  rawRows.value = sorted
  return sorted
}

const initialSelectedId = (): number | string | null => {
  const queryId = route.query.submissionId
  if (typeof queryId === 'string' && rawRows.value.some(row => String(row.id) === queryId)) return queryId
  return rawRows.value[0]?.id ?? null
}
```

首屏流程写死为：`onMounted(async () => { await loadQueue(); workspace.selectedId.value = initialSelectedId(); await workspace.refresh(); })`。`refresh()` 内部再次 `loadQueue()`（同一端点第二次请求，本期接受、不引入缓存层），第二次排序口径相同，不会改变既有选中 id 的相对顺序；`selectedId` 已由首屏预置为合法 id 或 null，Facade 不会覆盖非 null 值。若第二次请求失败则由 `request.ts` 拦截器统一提示，本期不额外处理。

**Facade 装配**：

```ts
const labStrategy = scoringStrategyOf('LAB')
const reportComment = ref('')

const workspace = useGradingWorkspace<LabReportDetail, GradingDraftState>({
  domain: 'LAB',
  loadQueue: async () => loadQueue(),
  loadDetail: id => getTeacherLabReportDetail(id),
  scoreLinesOf: detail => (detail.answers ?? detail.items ?? []).map(item => labStrategy.adapt(item)),
  draftPort: createSharedDraftPort<LabReportDetail>(d =>
    (d.answers ?? d.items ?? []).map(item => ({
      key: String(item.answerId ?? item.id ?? item.stepId),
      score: item.score ?? null,
      teacherComment: item.teacherComment ?? '',
    }))),
  statusOf: detail => detail.submitStatus,
  isReadOnly: status => labStrategy.isReadOnly(status),
  handlers: {
    saveGrade: async (detail, draft) => {
      if (!draft.marked.length) {
        ElMessage.warning('请先输入至少一道题的分数');
        return;
      }
      const items = (detail.answers ?? detail.items ?? [])
        .filter(item => draft.marked.includes(String(item.answerId ?? item.id ?? item.stepId)))
        .map(item => ({
          answerId: Number(item.answerId ?? 0),
          score: Number(draft.scores[String(item.answerId ?? item.id ?? item.stepId)] ?? 0),
          teacherComment: (draft.comments[String(item.answerId ?? item.id ?? item.stepId)] ?? '').trim(),
        }))
        .filter(item => Number.isFinite(item.answerId) && item.answerId > 0);
      if (!items.length) {
        ElMessage.warning('请先输入至少一道题的分数');
        return;
      }
      await gradeTeacherLabReport(detail.id, { items, teacherComment: reportComment.value.trim() });
      ElMessage.success('评分已保存，报告已结案');
    },
    saveAnswerGrade: async (detail, key) => {
      const item = (detail.answers ?? detail.items ?? []).find(i => String(i.answerId ?? i.id ?? i.stepId) === key);
      if (!item?.answerId) {
        ElMessage.warning('当前题项没有可确认的答案记录');
        return;
      }
      await confirmTeacherLabStepScore(detail.id, {
        answerId: item.answerId,
        score: Number(workspace.draft.value?.scores[key] ?? 0),
        teacherComment: (workspace.draft.value?.comments[key] ?? '').trim(),
        acceptSuggested: false,
      });
      ElMessage.success('题项评分已确认');
    },
    returnSubmission: async detail => {
      await returnTeacherLabReport(detail.id);
      ElMessage.success('已打回，学生可重新编辑提交');
    },
  },
})

const stepList = computed(() => (workspace.detail.value?.answers ?? workspace.detail.value?.items ?? [])
  .filter(i => i.stepId != null && i.stepNo != null)
  .map(i => ({ stepId: i.stepId!, stepNo: i.stepNo!, title: i.stepTitle || i.title || '' })))

watch(() => workspace.detail.value, d => {
  reportComment.value = d?.teacherComment ?? d?.reportComment ?? ''
})
```

`saveGrade` 的确认框在右栏「提交评分」按钮点击时先弹（`ElMessageBox.confirm('保存后评分将结案且不可修改，确认保存？', '保存评分', { confirmButtonText: '确认保存', cancelButtonText: '取消', type: 'warning' })`，确认后才 `workspace.save()`；handler 只发请求与 toast，不重复弹确认）。`loadQueue` 直接返回 `loadQueue()` 的排序原始行，Facade 内部自行归一，不重复归一。`watch` 需加入 script 的 vue import。

```ts

  workspace.detail.value?.submitStatus === SUBMISSION_STATUS.SUBMITTED
  || workspace.detail.value?.submitStatus === SUBMISSION_STATUS.GRADED,

const openReportView = () => {
  const studentId = workspace.detail.value?.studentId
  if (studentId == null) return
  const href = router.resolve({ name: 'teacher-lab-report-view', params: { labId: labId.value, studentId } }).href
  window.open(href, '_blank', 'noopener,noreferrer')
}
const goBatchGrade = () => {
  void workspace.guardBeforeSwitch(() => {
    router.push(`/teacher/lab-reports/${workspace.selectedId.value}/batch-grade`)
  })
}
const itemMaxScore = (item: LabReportAnswerItem): number =>
  labStrategy.adapt(item).maxScore ?? 0
const confirmStep = async (item: LabReportAnswerItem): Promise<void> => {
  const key = String(item.answerId ?? item.id ?? item.stepId)
  await workspace.saveAnswer(key)
}
const acceptSuggested = async (item: LabReportAnswerItem): Promise<void> => {
  if (!workspace.detail.value || item.answerId == null) return
  await confirmTeacherLabStepScore(workspace.detail.value.id, {
    answerId: item.answerId,
    acceptSuggested: true,
  })
  ElMessage.success('已采纳参考分')
  await workspace.refresh()
}
const handleReturn = async () => {
  if (!canReturn.value || !workspace.detail.value) return
  const msg = workspace.detail.value.submitStatus === SUBMISSION_STATUS.GRADED
    ? '该报告已批改，打回后成绩将清除，学生可重新编辑提交，是否继续？'
    : '打回后学生可修改作答并重新提交，是否继续？'
  try { await ElMessageBox.confirm(msg, '打回确认', { type: 'warning' }) } catch { return }
  await workspace.returnSubmission()
}
const submitWithConfirm = async () => {
  try {
    await ElMessageBox.confirm('保存后评分将结案且不可修改，确认保存？', '保存评分', {
      confirmButtonText: '确认保存', cancelButtonText: '取消', type: 'warning',
    })
  } catch { return }
  await workspace.save()
}
```

## 5. 关键行为与边界

| 场景 | 实现口径 |
|---|---|
| 队列数据源 | 全量队列一次拉取后按 `labId` 过滤；首屏预拉一次 + Facade `refresh()` 再拉一次，共两次请求，不引入缓存层 |
| `?submissionId` 合法 | 首屏 `selectedId` 预置为该值，`refresh()` 加载对应详情 |
| `?submissionId` 非法 / 缺参 | 预置为排序后首项 `id`；队列空时预置 `null`，Facade 不再自动选 |
| 切题草稿保护 | `workspace.selectSubmission()` 内 `guardBeforeSwitch` 弹确认，文案「当前评分尚未保存，确定切换吗？」（Facade 原文），不在页面另写 |
| 切题竞态 | Facade `selectionToken` 丢弃过期详情，不在页面另写 token |
| SAVED 报告 | `labStrategy.isReadOnly('SAVED')` 为 true → 只读预览；打回按钮 `disabled`；提交评分别禁用 |
| SUBMITTED / GRADED 报告 | 可评分 / 可打回；打回确认文案按状态分支 |
| 队列空 | 中栏 D13 空态文案，右栏空汇总；批量重判可点，其余选中态按钮隐藏 |
| 无提交学生 | 不进三栏队列；班级总览按 `submissionId == null` 显示「未提交」且不显示两按钮 |
| 单题确认分 | 采纳参考分：`acceptSuggested: true`、不传 `score`；手工确认：传 `score` 与 `teacherComment`、`acceptSuggested: false` |
| 整卷提交 | `gradeTeacherLabReport` 请求体 `{ items, teacherComment }`，`items` 仅含已标记且 `answerId` 合法者，`score = Number(score || 0)` |
| 图片展示 | `LabAnswerImageGallery` 复用，`extractReportImages(item)` 取图 |
| 行为摘要 | `BehaviorSummaryCard` 按当前 `submissionId` 取数；`stepList` 从当前详情 `answers/items` 生成 |
