## 2. 背景与问题（2026-11-25 现网实测）

作答页 `LabStepAnswerPanel.vue` 的 `section.lab-info-card`（L35–L65）横向占满全宽、纵向四块依次堆叠：实验指导 / 实验要求 / 实验内容 / 教师总评。存在三个问题：

| 编号 | 问题 | 证据 |
|---|---|---|
| P1 | 纵向占用过大：内容多为空态占位（未提供实验指导文件 / 暂无实验要求。/ 暂无实验内容。/ 当前尚未开放教师总评。），四块仍各占一行，整卡约 280px，挤压下方作答工作区 | 截图；`.lab-info-card { max-height: 38vh }`（L331–L336） |
| P2 | 视觉层级单调：蓝色大写字距标题 + 灰色正文纵向重复四次，无分组与留白节奏 | `.lab-info-section__title`（L355–L362） |
| P3 | 已批改只读态下学生主要诉求是逐题查看反馈，信息卡却恒定展开抢占首屏 | 截图 |

## 3. 已定决策清单（实现对照表）

## 8. 风险与回滚

| 风险 | 控制 |
|---|---|
| 默认收起导致学生跳过实验要求 | 副标题「先阅读实验要求与实验内容，再进入题目作答。」常显；展开一次点击可达 |
| 图标字号触发设计门禁 | 图标规则选择器含 `material-symbols-outlined`（门禁豁免块），且取值用 `var(--font-size-lg)` |
| 收起态遮挡下载入口 | 指导文件名与下载按钮在展开态可见，A4 验收覆盖；收起态由副标题提示 |
| 回滚 | 纯前端：`git checkout --` 还原 3 个文件即可，无数据与迁移回滚 |

## 10. 附录：已否决方案

| 否决项 | 原因 |
|---|---|
| 收起态加摘要 chips（指导/要求/内容有无） | 与展开态内容双份维护，同一信息两处表达；收起态用副标题提示已足够 |
| 默认态按「有无内容」动态展开 | 初始值依赖 detail 加载时序，需 watch 同步，引入不确定性分支；恒定收起更简单可测 |
| 信息卡移入左侧栏 | 侧栏 280px 定宽且为定高滚动区，长文本与下载按钮挤压题项导航 |
| 信息卡并入页头 | 页头已有 9 个 chip 信息饱和，且 PRD D3 写死信息卡为独立区 |
| 直接删除空态占位文字 | PRD D3 写死空态文案口径，改动超出「视觉细节」授权范围 |
| `el-collapse` 组件 | 全仓无使用先例，EP 折叠头样式与设计体系卡片骨架不一致，需额外样式覆盖 |
