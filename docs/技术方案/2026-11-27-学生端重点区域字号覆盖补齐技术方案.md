- **日期**：2026-11-27
- **状态**：**已定稿（决策写死，可直接编码）**

## 1. 背景与问题（可验证）

上一轮已把 11 档 token 放大，但复测截图中红框区域仍偏小。逐项定位后的可验证事实：

| # | 截图红框区域 | 现网生效值 | 根因 |
|---|---|---|---|
| P1 | 考试详情面包屑、侧栏导航、用户资料 | 面包屑 14/12px；`.nav-item` 14px；用户资料 14/12px | 已 token 化但停在 sm/xs 档，未用正文档 |
| P2 | 考试详情题目胶囊、选项、对错速览图例、结果说明 | 胶囊 12px；`.exam-option-review__title` 12px / `__key` 12px / `__label` 13px / `__tag` 11px；图例 12px；说明 12px | 部分用 xs 档，部分为 scoped 硬编码 px，完全不走 token |
| P3 | 作业列表元信息栅格 | 标签 14px；值被后置规则降为 12px（`Homeworks.vue:664-667`）；描述 12px | 后置覆写把前置 md 档降回 xs |
| P4 | 成绩反馈右侧优势项 / 待提升项 / 成绩解读 | 说明文字 12px；加粗标题 12px（`ScoresPanel.vue:1261-1275`） | 后置覆写把前置 base/md 档降回 xs |
| P5 | 门禁未拦截 | `components/exam/ExamOptionReview.vue` 不在 `designTokens.spec.ts` 的 #9/#10 扫描范围 | 硬编码 11/12/13px 未被发现 |

## 7. 已否决方案

| 否决项 | 原因 |
|---|---|
| 全局把 `xs 12→14` / `sm 14→16` | 会让密集表格与 Dialog 同步膨胀，且 xs/sm 与 base 档位相等，破坏层级 |
| 局部 CSS `zoom` / `transform: scale` | 破坏固定定位与滚动容器，且无法分档建立层级 |
| 在 `views/**` 新增 px 字号字面量 | 触发门禁 #8 / #9，违反 token 单一来源 |
| 逐页重写所有学生端页面 | 超出三张截图红框范围，回归面不可控 |
