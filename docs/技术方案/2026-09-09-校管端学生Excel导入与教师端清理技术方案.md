教师端第一期已移除导航与路由挂载，但 **`teacher/Students.vue` 仍保留完整 Excel + 文本导入实现**（约 1300+ 行），形成死代码；`xlsx` 仅被该文件引用。

## 4. 前端设计

### 4.1 新增 `frontend/src/utils/studentImport.ts`

从 `teacher/Students.vue` 迁出并导出以下符号（实现与现网教师页逻辑一致，文本密码默认改为 §0#6）：

| 导出 | 职责 |
|------|------|
| `REQUIRED_IMPORT_HEADERS` | 表头别名常量 |
| `parseStudentExcelFile(file: File): Promise<ImportStudentRow[]>` | 读 `.xlsx` 首个 sheet |
| `parseStudentImportText(text: string): ImportStudentRow[]` | 按行 CSV 解析 |
| `downloadStudentImportTemplate(): void` | 生成并下载模板 |

**类型**：从 `@/types/student` 引入 `ImportStudentRow`。

**`parseStudentImportText` 规则**：

```ts
// 每行：username, displayName, password（均可 trim）
// 有效行：username 与 displayName 均非空
// password = password.trim() || username
```

**`parseStudentExcelFile` 规则**：

- 非 `.xlsx` 由调用方在 UI 层提示「请上传 .xlsx 格式的 Excel 文件」。
- 首行表头映射见 §4.2；数据行从第 2 行起。
- 跳过「学号、姓名、密码全空」行；保留「学号+姓名齐全」行。
- 解析异常 `throw Error` 中文消息（工作表缺失、内容为空、表头缺列等），与教师页一致。

### 4.2 Excel 表头别名（精确匹配，区分大小写按单元格原文 trim 后比较）

| 字段 | 可接受表头 |
|------|-----------|
| `username` | `学号`、`账号`、`用户名` |
| `displayName` | `姓名`、`学生姓名` |
| `password` | `密码`、`初始密码`（列可缺失） |

缺 `username` 或 `displayName` 列 → 抛错「Excel 表头必须包含"学号"和"姓名"列」。

### 4.3 修改 `frontend/src/views/admin/Students.vue`

在现有导入弹窗上增量改造：

**顶部 `el-alert` 文案**（替换现网仅提及文本的提示）：

```text
请先选择班级后再导入。支持 Excel（.xlsx）或文本：学号,姓名,密码（每行一条）；Excel 表头为学号/姓名/密码，密码可空（默认学号）。
```

**状态新增**：

- `selectedImportFile: Ref<File | null>`
- `importFileName: Ref<string>`
- `parsedImportRows: Ref<ImportStudentRow[]>`
- `isImportDragOver: Ref<boolean>`

**Excel 区交互**（Element Plus）：

- `el-upload`：`accept=".xlsx"`、`auto-upload="false"`、`show-file-list="false"`。
- 外层 div 支持 dragenter/dragover/dragleave/drop（与教师页行为一致）。
- 按钮：「下载模板」「选择 Excel 文件」「清空文件」（仅 `selectedImportFile` 存在时显示清空）。
- 解析成功：`ElMessage.success('Excel 解析成功，共 N 条有效记录')`。
- 无有效行：`ElMessage.warning('Excel 中没有可导入的有效学生记录')` 并清空文件状态。

**`submitImport` 逻辑**：

```ts
const parsedRows =
  parsedImportRows.value.length > 0
    ? parsedImportRows.value
    : parseStudentImportText(importText.value);

if (!parsedRows.length) {
  ElMessage.warning('请先选择有效的 Excel 文件，或输入至少一条有效文本记录');
  return;
}
// 其后调用 importAdminStudents（不变）
```

**弹窗宽度**：由 `640px` 调整为 **`720px`**，容纳 Excel 区。

**样式**：在 `Students.vue` `<style scoped>` 增加 `.import-file-panel` 等最小样式（边框、拖拽高亮），**不**引入教师页 `teacher-dialog` 全局类。

### 4.4 移除 `admin/Students.vue` 内联 `parseImportTextRows`

删除页面内 `parseImportTextRows` 函数，统一改为调用 `parseStudentImportText`。

**`clearImportFile()`**（定义在 `admin/Students.vue` 脚本内）：重置 `selectedImportFile`、`importFileName`、`parsedImportRows`、`isImportDragOver`；`openImportDialog` 与「清空文件」按钮均调用它。

### 4.5 删除 `frontend/src/views/teacher/Students.vue`

- 文件**物理删除**。
- `router/index.ts` **不修改**（已无 component 引用，仅 redirect 保留）。
- `layout/index.vue` **不修改**（教师 mobile/侧栏已无学生入口）。

### 4.6 更新 `frontend/src/views/teacher/AGENTS.md`

删除「学生管理 | `Students.vue`」表格行及相关导入描述。
