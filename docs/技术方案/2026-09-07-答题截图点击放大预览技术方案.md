# 答题截图点击放大预览技术方案

**创建日期**：2026-09-07  
**状态**：已定稿（决策写死，可直接编码）  
**范围**：实验（Lab）域——学生端 `TextAnswerEditor` 答题截图缩略图点击全屏预览；同步统一教师端 `LabAnswerImageGallery` 多图切换行为  
**非目标**：作业/考试多图作答、定制预览工具栏、新预览 API、对象存储、后端改动

## 1. 背景与诉求

### 1.1 业务诉求

学生在实验作答页（含已提交/已批改只读态）上传的「答题截图」目前仅以 112×112 缩略图展示，无法放大查看终端细节，影响自查与阅读教师反馈时的体验。

### 1.2 现状结论

| 能力 | 现状 |
|------|------|
| 学生缩略图展示 | `TextAnswerEditor` 已通过 blob 加载缩略图 |
| 学生点击放大 | **无** |
| 教师缩略图 + 点击放大 | `LabAnswerImageGallery` 已有 `el-image-viewer` |
| 教师多图切换 | **无**（`url-list` 仅 `[viewerUrl]` 单张） |
| 教师 `teleported` | 现网**未传**（默认 `false`）；教师页通常无裁切问题，本期统一改为 `true` |
| 预览 API / 鉴权 | 已在《2026-09-04-实验子题文字与多图作答及教师汇总查看技术方案》定稿 |
| 作业/考试图片作答 | 未开通 `enable-images` |

### 1.3 设计结论（一句话）

在前端抽取统一的 `useLabAnswerImageViewer`，为学生 `TextAnswerEditor` 补齐点击全屏预览，并将教师 `LabAnswerImageGallery` 升级为按题多图 `url-list` 切换；两处 `el-image-viewer` **统一 `teleported`**；**不改动后端与存储**。

---

## 2. 目标与非目标

### 2.1 目标

1. 学生实验作答页：答题截图缩略图可点击全屏预览，遮罩覆盖整页且不被答题区裁切。
2. `SAVED` 编辑态与 `SUBMITTED` / `GRADED` 只读态均支持预览。
3. 单题 2～5 张图时，预览层可左右切换（学生端与教师端行为一致）。
4. 编辑态保留「删除」按钮，且与预览互不干扰。

### 2.2 非目标

- 不为作业/考试开通多图或预览（无 `enable-images`）。
- 不定制 `el-image-viewer` 工具栏（沿用组件内置缩放/旋转，不额外封装业务 UI）。
- 不改造预览 API、权限模型、落盘路径。
- 不把学生缩略图区替换为 `LabAnswerImageGallery`（编辑态需保留上传/删除，继续扩展 `TextAnswerEditor`）。

## 3. 前端方案（唯一路径）

### 3.1 新增 `useLabAnswerImageViewer.ts`

路径：`frontend/src/components/lab/useLabAnswerImageViewer.ts`

职责：

- 维护 `viewerVisible`、`viewerUrlList`、`viewerInitialIndex`
- 暴露 `openPreview(clickedPath: string, orderedPaths: string[], urlByPath: Record<string, string>)`
- 暴露 `closePreview()`

`openPreview` 算法（写死）：

```ts
const loaded = orderedPaths
  .map((path) => ({ path, url: urlByPath[path] }))
  .filter((item) => Boolean(item.url));

const index = loaded.findIndex((item) => item.path === clickedPath);
if (index < 0) return;

viewerUrlList.value = loaded.map((item) => item.url);
viewerInitialIndex.value = index;
viewerVisible.value = true;
```

`closePreview`：`viewerVisible = false`；`viewerUrlList = []`；`viewerInitialIndex = 0`。

### 3.2 修改 `TextAnswerEditor.vue`

**模板**：改为双根节点（作答区 + viewer）。

缩略图区：

```vue
<img
  :src="previewUrlOf(image.path)"
  :alt="image.name"
  class="text-answer-editor__thumb-image"
  @click="openPreview(
    image.path,
    currentImages.map((item) => item.path),
    previewUrlMap,
  )"
/>
<button
  v-if="!disabled"
  type="button"
  class="text-answer-editor__remove"
  @click.stop="removeImage(index)"
>
  删除
</button>
```

`previewUrlMap`：`computed` 合并 `remotePreviewUrls` 与 `localPreviewUrls`，**后者覆盖前者**：

```ts
const previewUrlMap = computed(() => ({
  ...remotePreviewUrls,
  ...localPreviewUrls,
}));
```

预览层：

```vue
<el-image-viewer
  v-if="viewerVisible && viewerUrlList.length"
  teleported
  :url-list="viewerUrlList"
  :initial-index="viewerInitialIndex"
  @close="closePreview"
/>
```

样式：将原 `.text-answer-editor__thumb img` 选择器改为 `.text-answer-editor__thumb-image`，并增加 `cursor: zoom-in`。

生命周期：

```ts
onBeforeUnmount(() => {
  closePreview();
  clearLocalPreviewUrls();
  clearRemotePreviewUrls();
});
```

**不改动**：上传、压缩、`saveAnswer` 链路、`images-removed` 事件。

### 3.3 重构 `LabAnswerImageGallery.vue`

- 删除组件内重复的 `viewerVisible` / `viewerUrl` / `openPreview` / `closePreview` 实现。
- 改为调用 `useLabAnswerImageViewer`。
- 缩略图点击：

```ts
openPreview(
  image.path,
  props.images.map((item) => item.path),
  previewUrls,
);
```

- `el-image-viewer` 绑定 composable 返回值，并**新增** `teleported`。
- 缩略图尺寸、caption、blob 加载与 revoke 逻辑**保持不变**。
- `onBeforeUnmount` 保持：先 `closePreview()`，再 `revokeAll()`。

### 3.4 依赖与注册

- `element-plus@^2.13.6` 已满足；`main.ts` 全量 `app.use(ElementPlus)`，**无需**单独注册 `ElImageViewer`。
- `initial-index` 对应 props `initialIndex`；配合 `v-if` 每次打开重新挂载，下标生效。

## 5. 端到端流程

```text
学生/教师页面展示缩略图
        │
        ├─ watch images → fetchLabAnswerImageBlobUrl(path) → previewUrls[path]
        │
        ▼
用户点击某缩略图
        │
        ├─ openPreview(clickedPath, orderedPaths, urlByPath)
        │     └─ 过滤已加载 URL → 计算 initial-index
        │
        ▼
el-image-viewer（teleported → body）全屏展示，可多图切换
        │
        ▼
@close → closePreview()（不 revoke 缩略图 blob）
```

## 6. 验收标准

1. 学生 `LabSteps`：`TEXT` / `SHORT_ANSWER` 子题有截图时，缩略图显示 `zoom-in` 光标，点击可全屏预览。
2. 预览遮罩覆盖整页视口，**不被**左侧题项导航或主答题区 `overflow:hidden` 裁切。
3. `SUBMITTED` / `GRADED` 只读态可预览；`SAVED` 编辑态可预览且「删除」仍可用（点击删除不打开预览）。
4. 单题 ≥2 张已加载截图时，预览层可切换查看全部已加载图片。
5. 某张图尚未加载完成或加载失败时，点击该缩略图无反应（不报错弹窗）。
6. 教师 `LabReportDetail` / `LabItemAnswersWall` / `LabReportBatchGrade` 中 Gallery：单图预览不退化，多图可切换。
7. 预览请求仍走鉴权 blob 链路；图片请求 URL 为 `/api/v1/labs/answer-images?path=...`，**不含** token query。
8. `cd frontend && npm run build` 通过。

## 8. 附录：已否决方案

| 否决项 | 原因 |
|--------|------|
| 新建 `frontend/src/composables/` 目录 | 仓库无此惯例；单文件不值得引入新顶层目录 |
| 仅在 `TextAnswerEditor` 内复制 Gallery 代码、不抽共享 | 学生/教师双份实现易漂移；Gallery 仍缺多图切换 |
| 只读态用 `LabAnswerImageGallery` 替换学生缩略图区 | 编辑态仍需上传/删除，无法整区替换 |
| 使用 `el-image` 的 `preview-src-list` | 与鉴权 blob 预加载、删除按钮叠层耦合更重；现网已用 `el-image-viewer` |
| token 或裸 path 作为预览 `src` | 违反已定鉴权方案 |
| 点击失败时 `ElMessage` 提示 | 与现网 Gallery 静默行为不一致 |
| `teleported` 不传 / 默认 `false` | `LabSteps` 多层 `overflow:hidden` 会裁切原位挂载的 viewer |
| `initial-index` 用 `images` 原数组下标 | 部分图未加载时切换错位 |
| 新增后端预览接口或缩略图接口 | 现有 API 足够 |
| 作业/考试同步开通预览 | 未开 `enable-images`，超出范围 |
