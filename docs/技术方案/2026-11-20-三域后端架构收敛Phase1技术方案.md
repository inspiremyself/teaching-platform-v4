### 4.2 D5：成绩可见性策略收敛

**4.2.1 新增 `grading/support/ScoreVisibilityPolicy.java`（TD4/TD5）**

```java
package com.opencode.teachingplatform.grading.support;

import com.opencode.teachingplatform.common.enums.ScoreVisibilityMode;

import java.time.OffsetDateTime;

/**
 * 三域成绩可见性判定策略。
 *
 * <p>三域共用 ScoreVisibilityMode 四模式，但 exam 要求全程 GRADED 前置门槛、
 * lab 的 IMMEDIATE 要求已有总分、homework 无前置门槛——这些差异以配置常量表达，
 * 避免三处 switch 各自演化。</p>
 */
public record ScoreVisibilityPolicy(boolean finalStateGate, boolean immediateRequiresScore) {

    public static final ScoreVisibilityPolicy LAB = new ScoreVisibilityPolicy(false, true);
    public static final ScoreVisibilityPolicy HOMEWORK = new ScoreVisibilityPolicy(false, false);
    public static final ScoreVisibilityPolicy EXAM = new ScoreVisibilityPolicy(true, false);

    public boolean isVisible(ScoreVisibilityMode mode,
                             boolean submissionPresent,
                             boolean finalState,
                             boolean scorePresent,
                             OffsetDateTime deadline,
                             boolean released) {
        if (!submissionPresent) {
            return false;
        }
        if (finalStateGate && !finalState) {
            return false;
        }
        ScoreVisibilityMode effective = mode == null ? ScoreVisibilityMode.AFTER_TEACHER_CONFIRM : mode;
        return switch (effective) {
            case IMMEDIATE -> immediateRequiresScore ? scorePresent : true;
            case AFTER_TEACHER_CONFIRM -> finalState;
            case AFTER_DEADLINE -> deadline != null && !OffsetDateTime.now().isBefore(deadline);
            case MANUAL_RELEASE -> released;
        };
    }
}
```

- 无 Spring 注解、无状态、无 `@Transactional`；`finalStateGate` / `immediateRequiresScore` 由常量固定，不开放构造。
- 不接收 `CurrentUser`、不做角色鉴权（三域现网方法均无 role 判断，见 §2 N4）。

**4.2.2 三处业务方法改为委派（TD6）**

### 4.3 D8：题型别名收敛

**4.3.1 `grading/enums/QuestionType.java`（TD7）**

保留 5 个枚举值，新增：

```java
public static QuestionType fromAlias(String raw) {
    if (raw == null || raw.isBlank()) {
        return null;
    }
    return switch (raw.trim().toUpperCase(Locale.ROOT)) {
        case "SINGLE", "SINGLE_CHOICE" -> SINGLE_CHOICE;
        case "MULTI", "MULTIPLE", "MULTIPLE_CHOICE" -> MULTIPLE_CHOICE;
        case "JUDGE", "TRUE_FALSE" -> TRUE_FALSE;
        case "FILL", "FILL_BLANK" -> FILL_BLANK;
        case "SHORT", "TEXT", "SUBJECTIVE", "CODE", "SHORT_ANSWER" -> SUBJECTIVE;
        default -> null;
    };
}

public boolean isObjective() {
    return this == SINGLE_CHOICE || this == MULTIPLE_CHOICE || this == TRUE_FALSE || this == FILL_BLANK;
}

public String legacyCode() {
    return switch (this) {
        case SINGLE_CHOICE -> "SINGLE";
        case MULTIPLE_CHOICE -> "MULTI";
        case TRUE_FALSE -> "JUDGE";
        case FILL_BLANK -> "FILL";
        case SUBJECTIVE -> "SHORT";
    };
}
```
