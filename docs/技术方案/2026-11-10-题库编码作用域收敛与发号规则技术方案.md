### 3.3 平台编码规则 H1–H5

新增 `question/service/QuestionCodeRules.java`（`package` 与 2 个 import 显式列出，符合 `backend-code-style.mdc` §1.1）：

```java
package com.opencode.teachingplatform.question.service;

import com.opencode.teachingplatform.common.exception.BusinessException;

import java.util.regex.Pattern;

public final class QuestionCodeRules {

    public static final int MAX_LENGTH = 64;
    private static final Pattern ALLOWED = Pattern.compile("^[A-Z0-9_-]+$");
    private static final Pattern HOMEWORK_AUTO = Pattern.compile("^HW\\d+$");
    private static final Pattern LAB_AUTO = Pattern.compile("^LAB\\d+S\\d+$");

    private QuestionCodeRules() {
    }

    public static void validateUserSubmitted(String normalized, boolean skipFormatRules) {
        if (normalized == null || normalized.isBlank()) {
            throw new BusinessException(40000, "题目编码不能为空");
        }
        if (normalized.length() > MAX_LENGTH) {
            throw new BusinessException(40000, "题目编码长度不能超过 64 个字符");
        }
        if (skipFormatRules) {
            return;
        }
        if (!ALLOWED.matcher(normalized).matches()) {
            throw new BusinessException(40000, "题目编码只能包含 A-Z、0-9、- 和 _");
        }
        if (HOMEWORK_AUTO.matcher(normalized).matches() || LAB_AUTO.matcher(normalized).matches()) {
            throw new BusinessException(40000, "题目编码不能使用系统自动编码格式（HW{数字} / LAB{数字}S{数字}）");
        }
    }
}
```

调用顺序写死：

1. `QuestionService.create`：`String normalized = normalizeCode(request.code());` → `QuestionCodeRules.validateUserSubmitted(normalized, false);` → TD11 判重 → `apply` → `save`。

### 6.1 `questionBankCodeUniqueIsOwnerScoped` 断言口径（写死）

`BusinessSchoolScopeSchemaTests` 复用 `sixIndexesExist` 的 `actualTables(meta, "question_bank")` 回查 H2 实际表名；断言按列组合、不按索引名（H2 索引名带 `_INDEX_C` 后缀，MySQL 索引名等于约束名）。新增方法按现有 import 补 `ArrayList` / `HashMap` / `List` / `Locale` / `Map`：

```java
@Test
void questionBankCodeUniqueIsOwnerScoped() throws Exception {
    Map<String, List<String>> uniqueColumnsByIndex = new HashMap<>();
    try (Connection connection = dataSource.getConnection()) {
        DatabaseMetaData meta = connection.getMetaData();
        for (String actual : actualTables(meta, "question_bank")) {
            try (ResultSet rs = meta.getIndexInfo(null, null, actual, false, false)) {
                while (rs.next()) {
                    if (rs.getBoolean("NON_UNIQUE")) {
                        continue;
                    }
                    String indexName = rs.getString("INDEX_NAME");
                    if (indexName == null) {
                        continue;
                    }
                    int position = rs.getShort("ORDINAL_POSITION");
                    String column = rs.getString("COLUMN_NAME").toLowerCase(Locale.ROOT);
                    List<String> columns = uniqueColumnsByIndex.computeIfAbsent(indexName, key -> new ArrayList<>());
                    while (columns.size() < position) {
                        columns.add("");
                    }
                    columns.set(position - 1, column);
                }
            }
        }
    }
    assertThat(uniqueColumnsByIndex.values())
            .contains(List.of("school_id", "created_by", "code"), List.of("school_id", "source_ref"))
            .doesNotContain(List.of("code"), List.of("source_ref"));
}
```

`NON_UNIQUE == false` 的索引集合里，主键索引 `["id"]` 属噪声，不参与断言；`source_ref` 允许为 NULL 不引入额外分支；`doesNotContain(List.of("source_ref"))` 同时覆盖 V22 的 `uk_question_bank_source_ref` 残留检查。`sixIndexesExist` 对 `IDX_QUESTION_BANK_SCHOOL_CREATED_BY` 的断言保持。

## 10. 已否决方案（实现级，需求级否决项引用 PRD 附录 A）

| 否决项 | 原因 |
|---|---|
| `V29` 用 `ALTER TABLE ... DROP CONSTRAINT IF EXISTS ...` 同时跑两方言 | MySQL 8.0.45 实测报 1064；H2 才支持 `IF EXISTS` |
| H2 侧静态写死自动约束名且不加双引号 | `DATABASE_TO_LOWER=TRUE` 下实测返回成功但不删除约束，迁移会静默残留全局唯一 |
| 新增 `h2Only` 占位符、新 profile 隔离方言 | PRD D6 / `backend-db-and-config.mdc` §2.3 禁止，且会破坏 4 个 profile 的单一来源 |
| MySQL 侧静态写死 `code`、`CONSTRAINT_C2` 任一名字 | 本机迁移库与全新库索引名不同，写死会漏删其中一种 |
| 重建 `question_bank` 表复制数据 | 违反 PRD D4「零回填、纯 DDL」，且牵动外键、自增与历史快照 |
| 修改 `QuestionImportDialog.vue` 的 `importDisabled` 加 `errorCount > 0` | 违反 PRD D24 / §5.2 前端只改两个文件的边界；TD21 在 `parseImportJson` 内收口已达到同一效果 |
| 把 H1–H5 全部写成 DTO `@Pattern` | 无法表达 D16 同值豁免，且会误伤 `HW{id}` / `LAB{id}S{no}` 系统自动码 |
| 改 `QuestionEditorDialog.vue` / `buildQuestionCode` 让教师自编码码 | PRD D12 / D24 写死本期不改 |
| 改 `translateIntegrityViolation` 的匹配条件去匹配新约束名 | §0.1 实测两方言异常文本仍含 `question_bank` + `code`，改动属无收益扩大面 |
| 为 `source_ref` 保留全局唯一索引 | PRD D5 / P5 写死唯一索引须与 `findBySourceRefAndSchoolId` 同粒度 |
