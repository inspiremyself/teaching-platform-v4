#### 4.1.2 登录流程（AuthService#login）

1. `List<SysUser> users = sysUserRepository.findAllByUsernameAndRole(request.username(), request.role());`
2. 解析学校编码：
   - `String schoolCode = request.schoolCode() == null ? null : request.schoolCode().trim();`
   - `schoolCode` 非空：
     - `Long schoolId = schoolRepository.findByCode(schoolCode).map(School::getId).orElse(null);`
     - `schoolId == null` → `LOGIN_ERROR`（`40101`）。
     - `users = users.stream().filter(u -> Objects.equals(u.getSchoolId(), schoolId)).toList();`
     - `users.isEmpty()` → `LOGIN_ERROR`。
   - `schoolCode` 为空：
     - `users.isEmpty()` → `LOGIN_ERROR`。
3. `users.size() > 1` → `BusinessException(40903, "该用户名在多个学校存在，请填写学校编码后重试")`。
4. `SysUser user = users.get(0);`，后续状态校验、密码校验、单会话处理、登录成功响应与现状一致。
5. 失败审计 `logLoginFailure` 保持现状；`40903` 不写「登录失败」审计（尚未确定账号，避免跨校信息写入错误学校维度）。

`school.code` 按 `trim()` 后原值精确匹配，不做大小写折叠。

### 4.4 FR-3 实验查重真实化（S3）

#### 4.4.1 新增 PlagiarismTaskWriter

`backend/src/main/java/com/opencode/teachingplatform/plagiarism/service/PlagiarismTaskWriter.java`：

```java
@Service
public class PlagiarismTaskWriter {
    private static final int SUMMARY_MAX_LENGTH = 255;
    private final PlagiarismTaskRepository repository;

    public PlagiarismTaskWriter(PlagiarismTaskRepository repository) {
        this.repository = repository;
    }

    @Transactional(propagation = Propagation.REQUIRES_NEW)
    public void write(BusinessType type, Long businessId, Long studentId,
                      Double rate, String topMatchSummary, String rawResultJson) {
        PlagiarismTask task = repository.findByBusinessTypeAndBusinessId(type, businessId)
                .orElseGet(PlagiarismTask::new);
        task.setBusinessType(type);
        task.setBusinessId(businessId);
        task.setStudentId(studentId);
        task.setStatus(PlagiarismStatus.COMPLETED);
        task.setSimilarityRate(rate);
        task.setTopMatchSummary(truncate(topMatchSummary));
        task.setRawResultJson(rawResultJson);
        repository.save(task);
    }

    private String truncate(String value) {
        return value == null || value.length() <= SUMMARY_MAX_LENGTH
                ? value
                : value.substring(0, SUMMARY_MAX_LENGTH);
    }
}
```

#### 4.4.2 LabService 查重

构造器注入 `LocalPlagiarismService` 与 `PlagiarismTaskWriter`。

在 `submitLab` 中：

```java
refreshSubmissionAfterScoring(lab, submission);
labBehaviorMetricsService.computeForSubmission(submission);
refreshPlagiarism(lab, submission);
```

`refreshPlagiarism` 必须是提交链路最后一个外部副作用：`PlagiarismTaskWriter` 以 `REQUIRES_NEW` 独立提交，若后续还有同事务写入失败，会留下孤立查重任务（见 §12）。分析与写入分两段 `try/catch`，任何失败都只降级 `plagiarismRate=0`，不阻断提交。

新增方法：

```java
private void refreshPlagiarism(Lab lab, LabSubmission submission) {
    LocalPlagiarismService.PlagiarismAnalysisResult result;
    try {
        String sourceText = labSubmissionText(submission.getId());
        if (sourceText.isBlank()) {
            submission.setPlagiarismRate(0D);
            labSubmissionRepository.save(submission);
            return;
        }
        List<LocalPlagiarismService.CandidateText> candidates =
                labSubmissionRepository.findByLabIdAndSubmitStatusIn(
                                lab.getId(), List.of(SubmissionStatus.SUBMITTED, SubmissionStatus.GRADED))
                        .stream()
                        .filter(candidate -> !Objects.equals(candidate.getId(), submission.getId()))
                        .map(candidate -> Map.entry(candidate, labSubmissionText(candidate.getId())))
                        .filter(entry -> !entry.getValue().isBlank())
                        .map(entry -> new LocalPlagiarismService.CandidateText(
                                resolveLabReference(lab, entry.getKey().getStudentId()), entry.getValue()))
                        .toList();
        result = localPlagiarismService.analyze(sourceText, candidates);
    } catch (Exception ex) {
        log.warn("实验查重分析失败，降级为 0: labId={}, submissionId={}", lab.getId(), submission.getId(), ex);
        submission.setPlagiarismRate(0D);
        labSubmissionRepository.save(submission);
        return;
    }

    try {
        submission.setPlagiarismRate(result.similarityRate());
        labSubmissionRepository.save(submission);
        plagiarismTaskWriter.write(BusinessType.LAB, submission.getId(), submission.getStudentId(),
                result.similarityRate(), result.topMatchSummary(), result.rawResultJson());
    } catch (Exception ex) {
        // writer 为 REQUIRES_NEW，其回滚不污染外层事务；此处只降级查重率
        log.warn("实验查重任务写入失败，降级为 0: labId={}, submissionId={}", lab.getId(), submission.getId(), ex);
        submission.setPlagiarismRate(0D);
        labSubmissionRepository.save(submission);
    }
}
```

```java
private boolean matchesPassword(String raw, String storedHash) {
    if (storedHash == null || storedHash.isBlank()) {
        return false;
    }
    if (storedHash.startsWith("{")) {
        return passwordEncoder.matches(raw, storedHash);
    }
    return raw.equals(storedHash);

private boolean needsUpgrade(String storedHash) {
    if (storedHash == null || storedHash.isBlank()) {

    // {noop} / 无前缀明文都必须升级；只有 {bcrypt} 才交给 upgradeEncoding 判强度
```

```java
@Service
public class ExamAutoSubmitService {
    private final ExamSubmissionRepository submissionRepository;
    private final ExamRepository examRepository;
    private final ExamService examService;

    @Transactional(propagation = Propagation.REQUIRES_NEW)
    public void autoSubmit(Long submissionId) {
        ExamSubmission submission = submissionRepository.findByIdForUpdate(submissionId).orElse(null);
        if (submission == null || submission.getStatus() != ExamSubmissionStatus.IN_PROGRESS) {
            return;
        }
        OffsetDateTime now = OffsetDateTime.now();
        if (submission.getDeadlineAt() == null
                || now.isBefore(submission.getDeadlineAt().plusSeconds(ExamService.SUBMIT_GRACE_SECONDS))) {
            return;
        }
        Exam exam = examRepository.findById(submission.getExamId())
                .orElseThrow(() -> new BusinessException(40400, "考试不存在"));
        examService.finalizeExamSubmission(submission, exam, Map.of());
    }
}
```

## 7. 数据库迁移 V24

文件：`backend/src/main/resources/db/migration/V24__course_material_school_scope.sql`

```sql
-- V24: 课程资料增加学校维度
-- 1) 清理 uploader 不存在或 uploader 未绑定学校的孤儿资料：
--    这些记录无法回填 school_id，保留会导致后续 NOT NULL 失败。
DELETE FROM course_material
WHERE uploader_user_id NOT IN (
    SELECT id FROM sys_user WHERE school_id IS NOT NULL
);

-- 2) 加列（先允许 NULL，便于回填）
ALTER TABLE course_material ADD COLUMN school_id BIGINT NULL;

-- 3) 按上传者所属学校回填
UPDATE course_material
SET school_id = (
    SELECT u.school_id FROM sys_user u WHERE u.id = course_material.uploader_user_id
)
WHERE school_id IS NULL;

-- 4) 收紧为 NOT NULL（MySQL: MODIFY COLUMN / H2: ALTER COLUMN）
ALTER TABLE course_material ${alterModifyColumn} school_id BIGINT NOT NULL;

-- 5) 联合索引：学校 + 可见性
CREATE INDEX idx_course_material_school_visibility
    ON course_material (school_id, visibility);
```

约束：

- 不修改 `V1`–`V23`。

## 12. 风险与应对

| 风险 | 应对 |
|---|---|
| 跨校同名登录新增学校编码，影响登录习惯 | 仅多匹配时要求；单校用户无感；错误编码不泄露账号存在性 |

| 自动交卷与手动交卷并发 | 行锁 + 状态复查 + `REQUIRES_NEW` 单条隔离 |
| 密码编码切换导致历史账号无法登录 | 带前缀 `matches` + 无前缀明文比较 + 登录后升级；发布前用演示账号验证 |

| 自动交卷任务污染单测 | 单测 profile `app.exam.auto-submit.enabled=false`；用例直接构造 Job |

### 13.2 已否决方案

| 否决项 | 原因 |
|---|---|
| 用 `findByUsernameAndRole` 捕获 `IncorrectResultSizeDataAccessException` 后返回 `40903` | 无法拿到候选学校集合，且异常语义不稳定；改为返回 `List` 显式判定 |
| 登录强制所有用户填写学校编码 | 破坏单校用户习惯；改为仅多匹配时要求 |
| `course_material.school_id` 允许 NULL 并运行时兜底 | 查询与下载会长期存在跨校漏洞；改为迁移期回填 + `NOT NULL` |
| 保留 `LabService.submissionRate` 作为查重率 | 该方法恒返回 `null`，且语义是单题作答率；删除以免混淆 |
| 实验查重失败时回滚整个提交 | 查重是辅助能力，不应阻断教学主流程；改为降级 0 |
| 密码继续 `{noop}` 明文 | 不满足安全要求；改用 Delegating + 登录升级 |
| 对无前缀历史哈希调用 `passwordEncoder.matches` | `DelegatingPasswordEncoder` 对无前缀 id 抛异常；改为 `raw.equals(hash)` |
| H2 控制台按 `app.h2.console.enabled` 属性放行 | 与现网 profile 启动方式不一致；改为 `Environment.acceptsProfiles("test")` |
| 前端倒计时继续用 `deadlineAt - Date.now()` | 依赖客户端时钟；改为服务端 `remainingSeconds` 基线 |
| 自动交卷复用请求体 | 断线场景无请求体；改为使用已持久化 `ExamAnswer` 草稿 |
| 自动交卷批量同一事务 | 单条失败会拖垮整批；改为 `REQUIRES_NEW` 单条事务 |
| 保留 `ScoreVisibilityMode \| string` | 使类型收敛失效；删除 |
| `40102` 只在错误分支处理 | 成功分支（HTTP 200 + 业务码）会漏掉；两分支统一 |
| 全局异常继续回显 `ex.getMessage()` | 泄露 SQL/表名/类名；改为固定文案 + 日志 |
