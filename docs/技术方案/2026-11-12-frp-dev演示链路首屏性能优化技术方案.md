## 3. 唯一实现路径

### 3.1 字体本地化（`frontend/src/assets/global.css` + `frontend/public/fonts/`）

**新增 3 个二进制文件**（由实施阶段用 `curl` 下载，不在方案内嵌二进制）：

| 文件名 | 来源 |
|---|---|
| `frontend/public/fonts/inter-latin-variable.woff2` | Google Fonts `family=Inter:wght@300..700` CSS 的 `/* latin */` 分片 woff2（实测 48,432 B） |
| `frontend/public/fonts/dm-sans-latin-variable.woff2` | Google Fonts `family=DM+Sans:wght@400..700` CSS 的 `/* latin */` 分片 woff2（实测 36,980 B） |
| `frontend/public/fonts/material-symbols-outlined-subset.woff2` | Google Fonts `family=Material Symbols Outlined` + `text=<图标名清单>` 返回的 `fonts.gstatic.com/l/font?kit=...` woff2 |

**图标名清单写死为下列字符串**（覆盖 `layout/navigation.ts` 的 `icon` 字段、模板静态 ligature、`toneBadge` 的动态值、`HomeworkAnswerPanel.vue:44` 的三态字面量、两个 `Materials.vue` 的 `fileIcon` 返回值）。以单个空格拼接作为 `text=` 值，实施阶段不得重新推导，V1 以「`text=` 参数与本清单逐字一致」为判据：

```text
account_balance account_tree add add_circle analytics arrow_back arrow_downward arrow_forward arrow_forward_ios arrow_upward article assignment assignment_turned_in attach_file badge bookmark_add campaign cancel chat check_circle checklist chevron_right cloud_done content_copy dashboard database dataset delete description domain download draft edit edit_note error event expand_more fact_check filter_list folder folder_zip grade groups history history_edu hourglass_top hub image info lock_clock logout mail menu_book movie north_east pending_actions person person_add picture_as_pdf play_circle priority_high publish quiz refresh rule save schedule school science search settings slideshow smart_toy subject sync table_chart task_alt timelapse timer tips_and_updates tune verified verified_user visibility
```

请求时带 Chrome UA 并使用 `curl -G --data-urlencode`，下载返回 CSS 中 `@font-face` 的 `src` URL。**3 个文件的唯一校验方式**：HTTP 200、`wc -c <文件>` > 0、`file <文件>` 输出含 `woff2` 或 `Web Open Font Format`；S2 记录三者实际字节数写入验收记录。`fonts.gstatic.com/l/font?kit=...` 端点不返回可靠 `Content-Length` / `Content-Type`（HEAD 实测 `content-length: 0`），不以响应头作为校验依据。

**S2 前置门禁（ligature 保留核对）**：子集文件下载后，在 `http://127.0.0.1:5173/login` 的 DevTools Console 注入三个 `<span class="material-symbols-outlined">` 元素，文本分别为 `school`、`error`、`picture_as_pdf`；三者均渲染为图标而非英文文本才继续 S3，任一显示文本则按 §8 回滚并停止实施。

**`global.css` 目标改动**：删除原第 2、4 行 `@import`；在文件首部（原 `@import` 位置）写入 3 条 `@font-face`；把第 412 行 `.material-symbols-outlined` 规则补齐为 Google CSS 的完整类定义并保留现网 `font-variation-settings`。目标内容写死如下：

### 3.2 `frontend/vite.config.ts`

在 `server` 对象内新增固定 `warmup`，其余键（`host`、`port`、`allowedHosts`、`proxy`）逐字保留，且不新增 `server.hmr` / `server.ws` 键：

```ts
  server: {
    host: '0.0.0.0',
    port: 5173,
    // 允许 cpolar 等内网穿透域名（免费隧道子域会变，用前导点匹配全部子域）
    allowedHosts: ['.cpolar.top', '.cpolar.cn'],
    warmup: {
      clientFiles: [
        './src/main.ts',
        './src/App.vue',
        './src/router/index.ts',
        './src/views/auth/Login.vue',
      ],
    },
    proxy: {
      '/api': {
        target: apiTarget,
        changeOrigin: true,
      },
    },
  },
```

Vite 5.4.19 类型定义已核实 `server.warmup?: { clientFiles?: string[]; ssrFiles?: string[] }`。当前 `customDomains` 为 IP，Vite 默认放行 IP，`allowedHosts` 本次不改。

### 3.3 `scripts/path-b/dev-public.sh`（新增）

```bash
#!/usr/bin/env bash
# 路径 B：对外演示（frp 内网穿透）启动入口；日常开发用 scripts/path-b/dev.sh
# 用法: ./scripts/path-b/dev-public.sh up
#       ./scripts/path-b/dev-public.sh down
#       ./scripts/path-b/dev-public.sh status
#       ./scripts/path-b/dev-public.sh logs backend
#       ./scripts/path-b/dev-public.sh logs frontend
set -euo pipefail

ROOT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)"

export SERVER_COMPRESSION_ENABLED=true
export APP_HTTP_ACCESS_LOG_ENABLED=false
export SPRING_DATASOURCE_HIKARI_MAXIMUM_POOL_SIZE=20
export SERVER_TOMCAT_THREADS_MAX=80
export LOGGING_LEVEL_COM_OPENCODE_TEACHINGPLATFORM=INFO

echo "==> 对外演示模式（frp dev）注入："
printf '    %s=%s\n' \
  SERVER_COMPRESSION_ENABLED "${SERVER_COMPRESSION_ENABLED}" \
  APP_HTTP_ACCESS_LOG_ENABLED "${APP_HTTP_ACCESS_LOG_ENABLED}" \
  SPRING_DATASOURCE_HIKARI_MAXIMUM_POOL_SIZE "${SPRING_DATASOURCE_HIKARI_MAXIMUM_POOL_SIZE}" \
  SERVER_TOMCAT_THREADS_MAX "${SERVER_TOMCAT_THREADS_MAX}" \
  LOGGING_LEVEL_COM_OPENCODE_TEACHINGPLATFORM "${LOGGING_LEVEL_COM_OPENCODE_TEACHINGPLATFORM}"

exec "${ROOT_DIR}/scripts/path-b/dev.sh" "$@"
```

脚本需可执行（`chmod +x`）。`dev.sh` 用 `nohup` 启动 `backend.sh` / `frontend.sh`，环境变量由子进程继承；`down/status/logs` 子命令同样透传，变量不生效但不产生副作用。`scripts/path-b/dev.sh`、`backend.sh`、`frontend.sh` 零改动。
