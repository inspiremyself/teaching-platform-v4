## 4. 统一内容契约

### 4.1 写入结构（唯一标准）

| 题型 | `type` | `optionsJson` | `answerJson` | `scoringConfigJson` |
|---|---|---|---|---|
| 单选 | `SINGLE` | `[{"key":"A","content":"..."}]` | `["A"]` | `null` |
| 多选 | `MULTI` | `[{"key":"A","content":"..."}]` | `["A","B"]` | `null`（评分策略缺省按 `FULL_MATCH`） |
| 判断 | `JUDGE` | `[{"key":"T","content":"正确"},{"key":"F","content":"错误"}]` | `["T"]`（或 `["F"]`） | `null` |
| 填空 | `FILL` | `null` | `[{"index":1,"answers":["答案1","别名1"]}]` | `null` |
| 简答 | `SHORT` | `null` | `["参考答案"]` | `null`（复制时若来源快照含 `keywords` 则原样写入） |
| 代码（仅实验内部） | `CODE` | `null` | `["参考实现或评分要点"]` | `{"language":"JAVA"}`，不落题库 |

约束：

- `answerJson` 始终是 JSON 数组，禁止写入对象形态；读取端可容忍对象形态，但新写入不产生。
- `scoringConfigJson` 只允许出现评分参数键：`mode`、`keywords`、`blanks`、`ignoreCase`、`language`、`rubric`；禁止放 `type` / `optionsJson` / `answerJson` / `analysisText`。
- 填空题的 `index` 从 1 开始连续递增；后端归一后按 `index` 升序。

### 4.2 选项归一函数

后端新增 `QuestionContentSupport.normalizeOptions(String optionsJson)`：

1. 解析为 `List<?>`；空或非法返回 `List.of()`。
2. 元素为 `Map`：取 `key`（缺省按位置生成 `A/B/C...`）与 `content`（回退 `label`、`text`）。
3. 元素为字符串：`key` 按位置生成，`content` 取字符串。
4. 输出 `List<Map<String,Object>>`，键固定为 `key`、`content`。

`buildQuestionSnapshot`、`addQuestionFromBank`、`updateQuestion`、`QuestionBankCopyService` 统一使用该函数。

### 4.3 校验矩阵

| 题型 | 规则 | 错误信息 |
|---|---|---|
| 通用 | `type` ∈ `SINGLE/MULTI/JUDGE/FILL/SHORT`（复制时实验 `CODE` 映射为 `SHORT`） | `不支持的题型：{type}` |
| 通用 | `stem` 去空白后非空 | `题干不能为空` |
| 通用 | `questionScore > 0` | `分值必须大于 0` |
| SINGLE | 选项 ≥ 2；答案数组长度 = 1；答案键 ∈ 选项键 | `单选题至少需要 2 个选项` / `请设置单选题正确答案` / `单选答案必须是选项之一` |
| MULTI | 选项 ≥ 2；答案数组非空；全部答案键 ∈ 选项键 | `多选题至少需要 2 个选项` / `请至少选择一个多选题正确答案` / `多选答案必须全部来自选项` |

| SHORT | `answerJson` 非空数组且至少 1 个非空白字符串；或 `scoringConfig.keywords` 非空 | `简答题参考答案或评分要点不能为空` |

`answerJson` 格式错误统一 `40000 题目答案 JSON 格式不正确`。

### 6.2 `GradingAdapter`

改造 `resolveScoringConfig`：

```java
private Map<String, Object> resolveScoringConfig(QuestionSnapshot snapshot, QuestionType type) {
    Map<String, Object> derived = deriveAnswerConfig(snapshot.answerJson(), type, snapshot.score());
    Map<String, Object> configured = readJsonMap(snapshot.scoringConfigJson());
    Map<String, Object> merged = new LinkedHashMap<>(derived);
    merged.putAll(configured);   // 评分参数覆盖，答案键缺省由 derived 兜底
    return merged;
}
```

`deriveAnswerConfig` 规则（输入 `type` 先经现有 `toGradingQuestionType` 归一为 `QuestionType`，不直接 `valueOf`）：

| 题型 | 来源 | 输出 |
|---|---|---|
| SINGLE / TRUE_FALSE | `answerJson` 为数组取首元素；为对象取 `correctAnswer` → `correct` → `answer`；为标量取自身 | `{correctAnswer: value}` |
| MULTIPLE | 数组整体；对象取 `correctAnswers` → `correctAnswer` → `answers` | `{correctAnswers: List<String>}` |
| FILL | 数组 `[{"index","answers"}]` 按 `index` 升序；对象取 `blanks` | `{blanks:[{answers:[...], score: 单空分值}]}`；`单空分值 = floor(题目分值 / 空数 * 100) / 100`，最后一个空的分值 = `题目分值 - 单空分值 * (空数 - 1)`，保证合计等于题目分值 |
| SUBJECTIVE | 不推导 | `{}` |

- `answerJson` 为空或无法解析时返回空 Map，由评分策略的空答案保护返回 0。
- 填空单空分值必须写入，否则 `FillBlankScoringStrategy` 读到 `score=0`。

### 6.3 评分策略

| 文件 | 改动 |
|---|---|
| `SingleChoiceScoringStrategy` | 预期答案为空时返回 0 分 |
| `TrueFalseScoringStrategy` | 预期答案为空返回 0；`normalizeJudge` 同时作用于期望答案与 `studentAnswer` |
| `MultipleChoiceScoringStrategy` | `expected.isEmpty()` 时返回 0（`FULL_MATCH` 与 `average_partial` 都适用） |
| `FillBlankScoringStrategy` | 不改结构；依赖 TD6 写入的单空分值 |

#### 6.4.3 `updateQuestion`

签名：`updateQuestion(CurrentUser, Long homeworkId, Long homeworkQuestionId, SaveHomeworkQuestionRequest)`。

1. `ownedHomework`；`homeworkQuestionRepository.findByIdAndHomeworkId(...)`，不存在返回 `40400`。
2. 状态校验：
   - `CLOSED` → `40000 作业已关闭，不能修改题目`。
   - `PUBLISHED` → 仅当 `sortOrder` 变化、其余字段与现有快照一致时允许；否则 `40000 已发布作业仅支持调整排序`。一致性比较必须用归一后结构，不得用原始字符串比较：
     - `type` 与快照 `type` 全等（大写）；
     - `stem.trim()` 与快照 `stem` 全等；
     - `normalizeOptions(optionsJson)` 与快照 `options` 按 `key` 升序逐项比较 `key` 与 `content`；
     - `readJsonRaw(answerJson)` 与快照 `answer` 做 JSON 深比较（数组按元素顺序，填空按 `index` 升序）；
     - `analysisText.trim()` 与快照 `analysisText` 全等（快照缺失视为 `""`）；
     - `questionScore` 与快照 `questionScore` 差值绝对值 `< 0.0001`；
     - `scoringConfigJson` 解析为 Map 后与快照 `scoringConfig` 深比较（空串与 `null` 等价）。
   - `DRAFT` → 全量允许，但若 `homeworkAnswerRepository.existsByHomeworkQuestionId(homeworkQuestionId)` 为真且 `questionScore` 与快照 `questionScore` 不一致，返回 `40000 该题目已有学生作答，不能修改分值`；其余字段（题干、选项、答案、解析、排序）仍允许修改。
3. 校验内容（`DRAFT` 全量校验；`PUBLISHED` 只改排序时不重复校验内容）。
4. 重建快照：保留 `questionId`、`fromBank` 与 `difficulty` 原值（新增题为 `MEDIUM`，历史快照缺 `difficulty` 也按 `MEDIUM`）；覆盖 `type/stem/questionScore/options`（`normalizeOptions(request.optionsJson())`）/`answer`（`readJsonRaw(request.answerJson())`）/`scoringConfig`（请求为空时保留原快照值）/`analysisText`。
5. 保存，返回 admin view。

#### 6.4.4 `deleteQuestion`

2. 仅 `DRAFT` 允许，否则 `40000 已发布或已关闭作业不能删除题目`。
3. `homeworkAnswerRepository.existsByHomeworkQuestionId(id)` 为真 → `40000 该题目已有学生作答，不能删除`。
4. 删除题目行；返回 `{deleted:true, id}`。

#### 6.5.1 `copyFromHomework` 流程

1. `requireTeacher`（`currentUser.role() == TEACHER`）。
2. `HomeworkQuestion question = homeworkQuestionRepository.findById(homeworkQuestionId)`，不存在 `40400`。
3. `Homework homework = homeworkRepository.findByIdAndCreatedBy(question.getHomeworkId(), currentUser.id())`，不存在 `40300`；`classAccessService.assertTeacherAssignedToClass`。
4. `question.getQuestionId() != null` → `40000 题库题无需复制`。
5. `sourceRef = "HOMEWORK:" + homeworkQuestionId`；`findBySourceRef` 命中 → 返回 `created=false`。
6. 读取快照，取 `type/stem/options/answer/scoringConfig/analysisText/difficulty`。快照 `options` 已是 `normalizeOptions` 归一后的 `[{key,content}]`，直接复用，不再二次解析；不产出分值（题库无分值字段）；快照缺 `analysisText` 时写 `""`，缺 `difficulty` 时写 `MEDIUM`。
7. `questionContentValidator.validate(...)`；失败返回 `40000` 并列出缺失字段。
8. 生成编码（TD15）。
9. 构造 `QuestionBank`：`sourceType=HOMEWORK_INLINE`、`sourceRef`、`createdBy=currentUser.id()`、`scoringConfigJson` 仅在快照配置非空时写入。
10. `save`；捕获 `DataIntegrityViolationException`：
    - 若 `source_ref` 冲突 → 重查返回 `created=false`；
    - 否则 → `40900 编码已在你的题库中存在`。
11. 计算 `duplicateQuestionId`（TD24）。
12. 审计 `QUESTION_CREATE`（`code`、`sourceType`、`sourceRef`）。
13. 返回 `{created:true, question:toView(saved), duplicateQuestionId}`。

#### 6.5.2 `copyFromLabStep` 流程

1. `requireTeacher`。
2. `LabStep step = labStepRepository.findById(stepId)`，不存在 `40400`。
3. `Lab lab = labRepository.findByIdAndCreatedBy(step.getLabId(), currentUser.id())`，不存在 `40300`；`classAccessService.assertTeacherAssignedToClass(currentUser, lab.getClassId())`。
4. `sourceRef = "LAB:" + step.getLabId() + ":" + stepId`；命中返回 `created=false`。
5. 解析 `step.answerConfigJson`，按 TD17 映射为题库字段，答案推导规则固定如下：
   - `SINGLE_CHOICE` / `MULTIPLE_CHOICE`：`options = [{key,content:label}]`（`key` 缺失按位置生成），`answerJson = JSON.stringify(correctAnswer)`（数组原样，空数组 → `40000`）。
   - `TRUE_FALSE`：`options = [{"key":"T","content":"正确"},{"key":"F","content":"错误"}]`，`answerJson = ["T"]` 或 `["F"]`（`TRUE/true/T/正确 → T`，`FALSE/false/F/错误 → F`，其他 → `40000`）。
   - `FILL_BLANK`：`answerJson = [{"index":n,"answers":[...]}]`，按 `blanks` 顺序从 1 编号，任一空 `answers` 为空 → `40000`。
   - `SHORT_ANSWER`：取 `keywords[].term` 以 `、` 拼接为 `["..."]`；`keywords` 为空时取非空 `experimentItemAnswer` 为 `["..."]`；两者皆空 → `40000 简答题参考答案或评分要点不能为空`。
   - `TEXT`：同 `SHORT_ANSWER`，`keywords` 优先，其次 `experimentItemAnswer`，皆空 → `40000`。
   - `CODE`：取 `rubric` 为 `["..."]`，为空时取非空 `experimentItemAnswer`，仍为空 → `40000`；`scoringConfigJson` 写入 `{"language": step.editorLanguage}`（缺省 `JAVA`）。
   - 其他类型 → `40000 该题项类型不支持复制到题库`。
6. 校验、编码（`LAB{labId}S{stepNo}`）、写入、并发兜底、重复提示、审计，同 6.5.1；不产出分值（题库无分值字段）、`difficulty = MEDIUM`、`analysisText = ""`。
7. 不写 `step.questionId`、不修改实验题项。

#### 6.5.3 响应视图

`toView(QuestionBank)` 在 `QuestionService.toView` 基础上增加：`sourceType`、`sourceRef`、`scoringConfigJson`。为避免重复实现，新增 `@Component QuestionBankViewMapper`（`question/service`），提供唯一方法 `Map<String, Object> toView(QuestionBank)`（沿用现有 `Map` 返回形态，不新增 DTO）；`QuestionService` 与 `QuestionBankCopyService` 均注入该 Mapper，不再各自实现视图转换。

## 10. 风险与已否决方案

### 10.1 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 历史内联题选项为空 | 复制到题库被拒绝 | 返回缺失字段提示；教师编辑保存后补齐 |
| 历史题库选项为字符串数组 | 旧结构无法直接反序列化 | TD2 归一读取 |
| 已发布作业排序仍需调用 `PUT` | 前端需提交完整内容 | TD9 只比较差异，内容一致时允许 |
| 复制与来源保存非同一事务 | 极端情况下来源回滚、题库题残留 | 复制只在前端确认保存成功后调用；`source_ref` 保留可人工识别 |
| 填空题历史对象形态 | 兼容读取 | TD6 同时接受数组与 `blanks` 对象 |

### 10.2 已否决方案

| 方案 | 否决原因 |
|---|---|
| 把 `answerJson` 改为 `{"correctAnswer":...}` 对象形态 | 需全量改序列化器、迁移历史数据、双读兼容，收益为零 |
| 在 `addInlineQuestion` 同一事务内完成复制 | 复制失败会标记事务回滚，违背“复制失败不影响作业保存” |
| 复制时按 `code` 幂等 | 编码可被教师修改，不能作为幂等依据 |
| 题库停用状态 | `question_bank` 无 `status`，快照已冻结，本期无引用拦截需求 |
| 新增单题详情接口 | 预填可直接使用列表返回的 `optionsJson/answerJson` |
| 批量排序接口 | PRD D25 明确逐条更新 |
