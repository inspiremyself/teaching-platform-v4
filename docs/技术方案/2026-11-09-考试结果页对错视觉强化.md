# 技术方案：学生端考试结果页对错视觉强化

**状态**：已定稿（决策写死，可直接编码）

## 1. 背景与目标

学生端考试结果页（`ExamAnswerPanel.vue` state `'C'`，`resultMode === 'result'`）当前对每题的对错没有任何视觉区分：对错只体现在「评分信息」小灰字（如「系统判定错误」），得分 `0/5` 与答对题一样使用页面主色 teal，学生需要逐字阅读才能发现哪题错了。

目标：在结果页逐题卡片、你的答案块、得分文本、汇总区强化「正确 / 错误 / 主观题待教师评分」三类视觉状态。

## 3. 实现说明（选定路径）

### 3.1 `useExamDetail.ts`

```ts
/** 结果页三态视觉：true→correct / false→wrong / null→manual；无判分条目→none */
function resultTone(questionId: number): 'correct' | 'wrong' | 'manual' | 'none' {
  const result = resultAnswerMap.value[questionId]
  if (!result) return 'none'
  if (result.isCorrect === true) return 'correct'
  if (result.isCorrect === false) return 'wrong'
  return 'manual'
}

const correctCount = computed(() =>
  Object.values(resultAnswerMap.value).filter(result => result.isCorrect === true).length
)

function scrollToResultQuestion(questionId: number) {
  document.getElementById(`result-question-${questionId}`)?.scrollIntoView({ behavior: 'smooth', block: 'start' })
}
```

三者加入 `useExamDetail` 末尾的返回对象（`ExamDetailKey` 注入消费，SFC 无需新增 import）。

### 3.2 `ExamAnswerPanel.vue`（仅 state `'C'` 结果区）

- 每题卡：根元素 `:id`、`:class="['result-question-card', ...]"`；**仅当 `resultTone(...) !== 'none'` 时追加修饰类** `` `result-question-card--${resultTone(...)}` ``（避免产生无效类 `result-question-card--none`）；头部徽章旁 `<span v-if="resultTone(...) !== 'none'" :class="['result-status-badge', ...]">` 图标 + 文案（文案映射：correct→回答正确 / wrong→回答错误 / manual→教师评分题）。
- 「你的答案」块：`:class` 按三态追加修饰类；块内首行左侧加图标。
- 得分文本：`:class` 按三态追加修饰类。
- 状态卡：`result-summary-card--status` 内追加 `<div v-if="questions.length" class="result-summary-card__desc">答对 {{ correctCount }} / 共 {{ questions.length }} 题</div>`。
- 右栏新增「对错速览」卡（结构：标题 + `question-map-grid` 复用 + 图例），按钮 `:class="['question-map-item', resultNavToneClass(...)]"`、`@click="scrollToResultQuestion(...)"`。

### 3.3 样式（scoped，新增 ~40 行）

新增 `.result-status-badge`（含三态修饰类）、`.result-question-card--correct/wrong/manual`（左边框色条）、`.result-answer-block--correct/wrong`、`.result-question-card__score--correct/wrong/manual`、`.question-map-item.is-correct/is-wrong/is-manual`。不改动任何现有类的定义。

## 5. 验收标准

以学生 `20260001` 查看一门已出分、含客观题与主观题的考试结果页：

1. 客观答对题：卡片左侧绿色条、头部绿色「✓ 回答正确」徽章、得分绿色。
2. 客观答错题：卡片左侧红色条、头部红色「✗ 回答错误」徽章、得分红色、「你的答案」块红底红字。
3. 主观题（`isCorrect === null`）：灰色「教师评分题」徽章、中性色条，无红绿着色。
4. 「状态」卡显示「答对 X / 共 Y 题」，X/Y 与逐题实际一致。
5. 右栏「对错速览」每个题号颜色与逐题状态一致；点击题号页面平滑滚动到对应题卡。
6. `grading`（主观题阅卷中）与 `pending`（成绩待发布）态页面与改动前完全一致。
7. 概览态与作答态（开始考试、答题、交卷流程）行为与样式无任何变化。

## 6. 非目标

- 不改教师端批改页、实验/作业结果页的对错展示（另立方案）。
- 不改后端 `ExamAnswerService` 判分口径、不改 `ExamAnswerDetail` 契约。
- 不做对错动画、音效、趋势统计（正确率历史曲线）。
- 不改结果页 `grading` / `pending` 两态的现有样式。
- 不在结果页引入答案回看交互之外的新操作（如对题申诉）。
