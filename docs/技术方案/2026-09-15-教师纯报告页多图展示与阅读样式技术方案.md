## 1. 背景与诉求

### 1.1 问题

教师在「实验报告」新标签页查看标准实验报告时，只能看到 `answerText` 文本框内容，**看不到**学生在《2026-09-04》已支持的答题截图。同一学生在「实验报告评分台」（`LabReportDetail`）或「子题答案墙」中图片正常。

### 1.2 根因（现网核对）

| 层级 | 评分台 `toTeacherReportItem` | 纯报告 `toTeacherReportViewStep` |
|------|-------------------------------|----------------------------------|
| 后端 | 含 `images` | **仅** `answerText` |
| 前端 | `LabAnswerImageGallery` | **无** Gallery |

2026-04 纯报告页设计未纳入多图字段；2026-09-04 明确主批改路径为 `lab-reports/{id}`，但队列仍保留 `report-view` 入口，形成体验断层。

### 1.3 设计结论（一句话）

在 `toTeacherReportViewStep` 补齐与批改详情一致的 `images`，报告页在解答区下方挂载现有 `LabAnswerImageGallery`，并用最小 CSS 提升长报告阅读性，**不**把页面改成管理工作台。

---

## 2. 目标与非目标

### 2.1 目标

1. 教师打开纯报告页时，每步若有答题截图，缩略图可见且可点击全屏预览（含多图切换，行为与 Gallery 现网一致）。
2. 纯文本步骤、无图步骤外观与现网一致（仅多图时出现 Gallery 区块）。
3. 报告页仍为白纸文档感，但长文步骤有清晰分节。

### 2.2 非目标

- 不调整 `LabReports.vue` 按钮文案与跳转参数。
- 不把报告页改为 `LabReportDetail` 布局或增加返回/批改工具条。
- 不为学生端、不修改上传/压缩/粘贴链路。
- 不新增 `extractReportImages` 调用（报告 API 直接返回 `images`，**不**再下发 `answerPayloadJson`）。

## 3. 后端方案（唯一路径）

### 3.1 修改点

文件：`backend/src/main/java/com/opencode/teachingplatform/lab/service/LabService.java`

方法：`private Map<String, Object> toTeacherReportViewStep(LabStep step, List<LabStepAnswer> answers)`

在现有 `answerText` 赋值之后增加一行（与 `toTeacherReportItem` 第 1355 行同逻辑）：

```java
item.put("images", answer == null ? List.of() : toAnswerImageViews(answer.getAnswerJson()));
```

**禁止**复制粘贴为独立工具类；**禁止**改 `getTeacherLabReportView` 的权限与最新提交解析逻辑。

### 3.2 接口契约

路径不变：`GET /api/v1/teacher/labs/{labId}/report-view/{studentId}`

`steps[]` 每项在现有字段基础上增加：

| 字段 | 类型 | 说明 |
|------|------|------|
| `images` | `array` | 元素含 `path`, `name`, `contentType`, `size`；顺序与 `answerJson.images` 一致 |

其余顶层字段（`reportTitle`、`totalScore` 未批改时为 `null` 等）**不变**。

## 4. 前端方案（唯一路径）

### 4.1 类型

文件：`frontend/src/types/lab.ts`

在 `TeacherLabReportViewStep` 中增加：

```ts
images?: LabAnswerImageMeta[];
```

### 4.2 页面

文件：`frontend/src/views/teacher/LabReportViewPage.vue`

1. `import LabAnswerImageGallery from '@/components/lab/LabAnswerImageGallery.vue'`
2. 模板：在解答文字框后追加：

```vue
<LabAnswerImageGallery
  v-if="step.images?.length"
  :images="step.images"
/>
```

3. 样式（scoped，写死数值）：
   - `.lab-report-sheet { max-width: 880px; margin: 0 auto; }`
   - `.lab-report-step { padding-bottom: 18px; margin-bottom: 18px; border-bottom: 1px solid #e5e7eb; }`
   - `.lab-report-section:last-of-type .lab-report-step:last-child` **不**需要特殊去边线（最后一步仍在「三、实验步骤」节内，保持与现网一致：所有步骤均有底边线，第四节小结无步骤列表）

**说明**：「三、实验步骤」内最后一步保留底边线，与第四节之间已有 `lab-report-section` 间距；**不**为最后一步单独 `:last-child` 去线。

### 4.3 不改动文件

- `frontend/src/api/labs.ts`（`getTeacherLabReportView` 已存在）
- `frontend/src/components/lab/LabAnswerImageGallery.vue`
- `frontend/src/router/index.ts`（路由已注册在 Layout 外）
- `frontend/src/views/teacher/LabReports.vue`

## 9. 附录：已否决方案

| 否决项 | 原因 |
|--------|------|
| 报告页整页套用 `LabReportDetail` 的 `page-header` / `answer-card` | 违背 2026-04 纯报告定位 |
| 前端二次请求 `lab-reports/{id}` 拼装图片 | 重复请求、依赖 submissionId，与 `labId+studentId` 入口语义冲突 |
| 报告 API 下发 `answerPayloadJson` 前端 `extractReportImages` | 与批改详情双轨；后端已有 `toAnswerImageViews` |
| 修改 `LabAnswerImageGallery` 增加 `variant="document"` | 本期范围仅需默认缩略图；避免牵动评分台/答案墙 |
| 解答框内嵌 `<img>` 裸 `path` | 违反《2026-09-04》鉴权拉 blob 规则 |
| 新建 Flyway 或报告落库表 | 图片已在 `lab_step_answer.answer_json` |
