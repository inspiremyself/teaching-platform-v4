## 3. 目标与非目标

### 3.1 目标

1. 三页基础展示件（统计胶囊、工具条、空态、状态解析、按钮实现）各只有一种表达。
2. 三页的域差异只体现在信息列、文案、跳转与确认策略，不体现在基础视觉规格。
3. 请求失败时三页都有可读的错误态与重新加载入口。
4. 取消实验列表的伪进度展示，不引入新数据契约。
5. 规范与事实口径回写单一来源，不新增第二份规范文档。

### 3.2 非目标（明确否决）

| 非目标 | 结论与理由 |
|---|---|
| 抽 `StudentTaskCard` / 通用任务列表页组件 | 否决，见 §9；三域字段、能力判断与跳转差异会转化为组件内域分支 |
| 合并 `components/ui/` 与 `workbench/` 两套共享层 | 否决；两者管辖层级不同，合并会覆盖教师端已验证模板 |
| 迁移页头到 `AppPageHeader` | 否决，见 §9；三页页头含角色专属视觉变体与既有全局类级联 |
| 统一三页按钮文案、状态文案、统计文案 | 否决；文案是业务语义（11-25 PRD D6），本期只统一机制 |
| 改 API、DTO、`types/`、`request.ts`、状态机、评分、考试计时与开考弹窗 | 否决；本期为展示层治理，契约零改动 |
| 改作业域业务逻辑与学生端其它页面（`Dashboard`、`Materials`、`ScoresPanel`） | 否决；作业域在 11-24 PRD D9 已定为零改动基准 |
| 改教师端面板结构、校管端、平台超管、后端、Flyway、权限 | 否决；本期只含教师端一处按钮文案 |
| 引入新依赖、新 UI 库、Tailwind、截图快照测试 | 否决；沿用现有 vitest 源码断言与既有门禁 |

## 4. 需求明细

### 4.1 P1：学生端三张列表页

**FR-1 统计胶囊（D3）**：三页统计区全部由 `AppMetaChip` 渲染，导入路径统一为 `@/components/ui/AppMetaChip.vue`。实验保持 3 枚及其现有 `value` / `label` / `tone="accent"` 组合；作业与考试把 4 个 `workbench-meta__item` 节点逐一改写为 `AppMetaChip`，`value` 取原 `<strong>` 内数值，`label` 取原后续文本。两页第 4 枚的 `--accent` 变体（`Homeworks.vue:17`、`exams/List.vue:18`）改为 `tone="accent"`。统计项的计算表达式与文案逐字保留。页头根元素与 `h1` 保留原位。

**FR-2 工具条容器（D4）**：三页工具条统一 `<AppToolbarCard>`。实验保持现值；作业把 `<section class="student-toolbar-card">` 改为 `<AppToolbarCard class="student-toolbar-card">`；考试把 `<section class="exams-toolbar-card">` 改为 `<AppToolbarCard class="exams-toolbar-card">`。两页 scoped 中与全局 `.toolbar-card` 等价的 `border` / `background` / `box-shadow` / `padding` 声明删除，私有变体（圆角、内部布局）保留。内部 `el-input` / `el-select` / `el-button` 与筛选 meta 文案逐字保留。

**FR-3 任务卡骨架（D5）**：在 `assets/layout.css` 新增 `.app-task-card` 与 `.app-task-meta-grid` 两个骨架类，取值只引用 `tokens.css` 变量，分别为卡片外壳（描边、圆角、背景、阴影、内间距）与信息栅格（`display: grid`、`gap`、列宽）。`.app-task-card` 加在三页 `<article>` 根节点（实验 `student-lab-card`、作业 `student-homework-card student-homework-card--compact`、考试 `exam-card exam-card--compact`）；`.app-task-meta-grid` 加在三页信息行（实验 `student-lab-card__meta-grid`、`Homeworks.vue:75` 的 `student-homework-card__info-row`、`exams/List.vue:57` 的 `exam-card__info-row`）。三页页面私有类保留；scoped 中只删除与两个新类等价的 `border` / `background` / `box-shadow` / `border-radius` / `grid-template-columns` / `gap` 声明，页面私有视觉变体（实验 16px 圆角）保留在私有类上。三页信息列的列数、标题与顺序不改：实验「班级 / 题项 / 截止 / 结果」，作业「作业状态 / 截止时间 / 当前结果 / 提交状态」，考试「考试窗口 / 时长 / 操作提示」。

**FR-4 状态解析（D6）**：实验页删除本地 `taskStatusLabel` 与 `submissionTagType` 的状态标签映射，`statusFilterLabel` 保留用于筛选项与 meta 文案；卡片标签改为 `resolveStatusPresentation({ module: 'lab', kind: 'submission', scene: 'student', status: row.submissionStatus, unknownLabel: '待开始' })`，色值经 `toElTagType(tone, 'info')` 得到 `el-tag :type`。`statusPresentation.ts` 的基表与覆盖表零改动：SAVED 沿用既有「已保存草稿」/ `info`，与 `useStudentLabSteps.ts:476` 的学生实验作答页同口径；`SUBMITTED` / `GRADED` 沿用基表；无状态值走 `unknownLabel` 与 `neutral`。筛选项四个文案留在 `Labs.vue` 的 `el-option` 中，不删除。实验 SAVED 标签由现网「进行中」/ `primary` 归一为「已保存草稿」/ `info`，两项均登记为 A5 允许变化，不扩展 `StatusTone` 五值，不修改 `statusPresentation.spec.ts`。作业与考试页的共享调用不变。考试页 `statusTone(row)` 的四态 stage 色板保留（能力态不是活动状态），不改类名与取值。

## 9. 已否决方案

| 否决项 | 原因 |
|---|---|
| 抽 `StudentTaskCard` 通用任务卡组件 | 三域字段（4 / 4 / 3 列）、能力判断与跳转差异会转成组件内域分支；且违反 11-25 存量收敛 PRD D6 与 11-24 PRD `FR-15` |
| 合并 `components/ui/` 与 `workbench/` 两套共享层 | 全站基础原子与教师高密度模板管辖层级不同，合并回归面覆盖教师端三域已验证页面 |
| 迁移页头到 `AppPageHeader` | 实验页有 16px 渐变头部变体（11-24 PRD `FR-8` 保留项），作业与考试页依赖 `global.css` 的 `workbench-header` 级联；强制迁移产生可见位移，收益低于风险 |
| 统一三页按钮文案与状态文案 | 文案承载提交状态与域能力语义，11-25 展示口径 PRD D6 明确不得统一 |
| 保留实验进度条并填充「真实进度」 | 列表 API 无已作答数，新增字段要改后端契约，超出本期范围；伪数据必须移除 |
| 把考试四态 stage 色板并入 `statusPresentation` | stage 由 `canStart` / `canResume` 等能力派生，不是活动状态；合并会改变语义来源 |
| 用截图快照测试替代源码断言 | 需引入浏览器测试依赖与基线图片仓库，超出既有工具链约束 |
| 扩展 `StatusTone` 五值以保留实验 `primary` | 11-25 展示口径 PRD D4 写死五值；为单一标签扩色板会污染全站状态语义，改由 A5 登记唯一色差 |
