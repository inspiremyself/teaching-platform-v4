## 3. 目标与非目标

### 3.1 目标

1. 学生在实验、作业、考试三域之间切换时，「从列表进入任务」的路径层级与交互心智完全一致：列表 → 单页作答容器，一跳直达。
2. 实验中转页删除后信息零丢失：实验要求、实验内容、实验指导下载、教师总评、实验小结在作答页全部可见。
3. 考试开考保留显式确认闸门（弹窗），对继续作答、查看结果、查看进度等路径零打扰；开考确认信息完整（窗口、时长、须知）。
4. 无后端、数据库、契约、权限变更；真实服务与真实账号下三域链路全绿。

### 3.2 非目标（明确否决）

| 非目标 | 结论与理由 |
|---|---|
| 合并三域作答面板为一个通用组件 | 三域题型、导航、计时差异大，收益低于风险；各域面板保留 |
| 修改三域提交状态机、评分、草稿、自动交卷逻辑 | 本次只动进入路径与页面层级（D12） |
| 删除考试 A 态页面（连直连兜底也去掉） | 直接 URL 访问未开考考试将无处呈现，且 canStart 直连不得自动开考，需最小兜底（D6） |
| 开考确认信息塞进列表卡 | 列表信息密度饱和且无法承载不可逆动作的确认语义（P4、P5） |
| 保留 `labs/:id → steps` 的 redirect 兼容跳转 | 无外部入口依赖，按「彻底删除废弃代码、不留兼容残留」原则处理 |
| 教师端、校管端、成绩页、资料页、Dashboard 页面调整 | 本期只覆盖学生端三域任务进入链路 |
| 新增依赖、组件库、测试插件 | 沿用 Vue 3 + Element Plus + vitest 现状 |

## 4. 需求明细

### 4.1 Phase A：实验域两层收敛

**FR-1 列表直达**：`Labs.vue` 行主按钮（文案映射沿用现状：开始实验 / 继续实验 / 查看详情 / 查看结果）点击直接 `router.push('/student/labs/:id/steps')`，不再进入 detail 路由；按钮文案与状态映射逻辑不变。

**FR-2 实验信息迁入**：`LabStepAnswerPanel.vue` 按 D3 落地——①页头 meta 追加实验类型、总分与计划满分、开始 / 截止、「实验尚未开始 / 已截止」chip；②题项区上方新增「实验信息」区（实验指导下载、实验要求、实验内容、教师总评）；③页尾既有「实验小结」卡承载 `summaryText`，不新增预览；④题项导航在 `showLabScore` 时追加每题得分「得分 x/stepScore」。概览信息在编辑态与只读态均展示，文案与空态按 D3 写死，不得缺失；除「是否可折叠 / 卡片样式」这一视觉细节外不做取舍。

**FR-3 路由与文件清理**：按 D2 删除 `router/index.ts` L68 路由条目、`views/student/LabDetail.vue` 文件、`breadcrumb.ts` L142-145 配置块与 L41 类型联合成员、L148-151 steps 面包屑中间段；`student-lab-steps` 面包屑改为「实验任务 / 题项作答」。完成后全仓 grep `student-lab-detail`、学生端 `LabDetail.vue` 引用均为 0。

**FR-4 状态机零改动**：作答、逐题保存、草稿、提交、只读、反馈链路沿用现有 `useStudentLabSteps` 全部逻辑；概览区为纯展示，不引入新的状态判定。

### 4.2 Phase B：考试域开考弹窗化

**FR-5 开考确认弹窗**：`exams/List.vue` 中 `canStart` 行主按钮点击打开确认弹窗，实现固定为 Element Plus `el-dialog`（项目唯一弹窗体系，不引入其他实现），宽度与内部样式由技术方案定。弹窗固定展示：考试标题、班级、考试窗口、时长、作答须知 3 条（文案沿用 A 态现网）、legacy 提示（`row.status === PUBLISHED && !row.endAt` 时显示「本场未设置统一截止时间，按个人限时收卷」）、未开始时确认按钮禁用并提示开始时间。确认按钮「开始考试」→ 调用 `startExam(row.id)`：成功后关闭弹窗、跳转 `/student/exams/:id`（页面 `loadExam` 到 `IN_PROGRESS` 自动回答题态并启动倒计时与草稿回填，页面侧无配合改动）；失败展示服务端错误、留在弹窗可重试或取消。弹窗打开与确认均不新增详情请求，仅用列表行字段。列表文案按 D5 同步改写：`actionText` canStart →「开始考试」、locked →「暂不可用」；`actionHint` canStart →「确认考试信息后进入答题，开始后连续计时。」。
