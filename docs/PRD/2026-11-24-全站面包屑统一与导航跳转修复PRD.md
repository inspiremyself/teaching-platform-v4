## 3. 目标与成功标准

1. 三类角色在任意业务页面都能看到与信息架构一致的面包屑，中间层级可点击并正确跳转。
2. 面包屑文案与侧边栏 label、左上角品牌名同源，全站不再出现自造角色前缀。
3. 5 个缺口页面补齐面包屑。
4. 移动端不因面包屑挤压内容；满高批改页不出现多出 34px 的滚动条。
5. 后端、数据、权限、`api/` 契约零改动；构建与测试全绿。

**成功标准**：`t9001/123456` 进入「考试」→ 面包屑为 `教学工作台 / 考试`，点「教学工作台」回工作台；进入某考试结果页 → `教学工作台 / 考试 / 考试结果`，点「考试」回考试列表，末段不可点；`platform9001/123456` 进入 `/admin/platform-content` → `平台管理台 / 平台内容`；`20260001/123456` 进入作业作答页 → `学习工作台 / 作业任务 / 作业详情`；窗口宽度 < 900px 时面包屑隐藏。

## 5. 术语

| 术语 | 含义 |
|---|---|
| 面包屑 | 页面顶部的层级路径导航，首项为角色空间，末项为当前页 |
| 页面级 eyebrow | 位于页面 `h1` 上方、用于标识页面位置的单行文字（本次要删除的 31 处） |
| 微标签 eyebrow | 卡片标题、弹窗标题、步骤条、状态徽标上的小字（本次保留） |
| 角色根 | 由 `resolveRoleView().brandText` 生成的第一段 |
| 静态末段 | 不带 `to` 的当前页面语义名，如「考试结果」 |

## 6. 口径与核心流程

### 6.1 渲染与跳转流程

1. 路由切换完成 → `AppBreadcrumb` 读取 `route.meta.breadcrumb`。
2. 若无该字段（登录页、重定向、catch-all）→ 组件不渲染，不占高度。
3. 有该字段 → 组装 `[角色根, ...meta.breadcrumb]`；角色根取 `resolveRoleView(authStore.user?.role).brandText`，`to` 取 `authStore.homePath`。
4. 中间段渲染 `<router-link>`；末段渲染 `<span aria-current="page">`；分隔符为 ` / `，`aria-hidden`。
5. 点击中间段执行标准路由跳转；目标与当前路由相同时由 `vue-router` 去重，不产生额外导航。

## 14. 风险与后续迭代

### 14.1 风险

- **满高布局**：批改工作区依赖 `100vh - 4rem`；若 flex 改造遗漏某页，会出现 34px 溢出。由 D4/FR-5 写死，并在 §12.3 逐项验收。
- **误删微标签**：130 处 eyebrow 中仅 31 处该删。由 §13.1/§13.2 两份清单逐文件核对，技术方案落地时用文件级清单而非正则批量删除。
- **平台超管首项错位**：共用 `/admin` 壳层，若从路由静态写首项会显示「学校管理台」。由 D2 从 `brandText` 取首项规避。
- **Layout 外页面遗漏**：`LabReportViewPage` 不在壳层内，易漏。由 FR-4 单列。

### 14.2 后续迭代

- 动态实体名末级（实验名 / 考试名 / 学生姓名），需另立 PRD。
- 面包屑折叠与长文本省略策略，当前文案均短，暂不需要。
- 若引入视觉回归测试，需同步更新 31 页截图基线，另立任务。
