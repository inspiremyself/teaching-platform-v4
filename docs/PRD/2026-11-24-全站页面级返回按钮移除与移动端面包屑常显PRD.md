## 3. 目标与成功标准

1. 页面级「返回上一级」能力全站收敛到面包屑单一入口，同屏不再出现双路径。
2. 删除后的按钮不留任何死代码（节点 / 函数 / 样式 / 导入）。
3. 移动端深层页面保留一条显式回退路径（面包屑紧凑常显）。
4. 后端、数据、权限、`api/` 契约零改动；构建与测试全绿。

**成功标准**：`20260001/123456` 提交考试进入结果页 → 页头无「返回考试列表」，点面包屑「考试任务」回 `/student/exams`；`t9001/123456` 打开实验结果三栏页 → 无「返回实验台账」，点面包屑「实验」回台账；评分台页头无「返回」但表单「取消」仍在；批量快捷批改页仅剩「回到详细批改」一个回详情入口；375px 视口下面包屑紧凑常显、任意深层页可达父级；`npm run lint && npm test && npm run build` 全绿且 3 个改写 spec 通过。

## 5. 术语

| 术语 | 含义 |
|---|---|
| 页面级返回按钮 | 位于页面（或页头/工作台动作区）头部、跳转目标为面包屑任一父级段对应路由的按钮 |
| 四件套删除 | 按钮模板节点、专属事件函数、专属 CSS、失效导入一并删除 |
| 队列工作流动作 | 批改队列内「上一个/下一个班级·学生」「回到详细批改」等模式与顺序导航，不承担页面级返回职责 |
| 紧凑常显 | 移动端（`< 900px`）面包屑不隐藏，以缩小字号、允许换行的方式常驻显示 |

## 6. 口径与核心流程

### 6.1 判定口径（R2 的展开）

一个按钮是否移除，**只看跳转目标**，不看文案与样式：

1. 目标路由 = 该页面包屑任一父级段的路由 → 移除（17 处全部命中）。
2. 目标为表单放弃、页内题目切换、批改队列顺序/模式切换 → 保留（D3）。
3. 文案含「返回」但为说明文字/注释 → 不动（D3-⑤）。
