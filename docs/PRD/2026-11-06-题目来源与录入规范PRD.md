## 2. 背景与目标

### 2.1 背景

平台同时存在题库、作业、实验、考试四条与题目相关的链路，但题目来源与录入方式并不一致，已经产生实质缺陷：

- 作业内联题只保存题型、题干、分值与一段评分配置，选项和标准答案在落库时被丢弃，导致学生端看不到选项、客观题答对判 0 分、空作答反而可能拿满分。
- 作业编辑保存时会把所有配置题再次追加，产生重复题目。
- 作业请求体存在 `saveToQuestionBank` 字段，但后端从未处理，前端固定传 `false`，是一个误导性死字段。
- 实验保存题项时自动创建题库题，编码包含秒级时间戳且无来源字段，导致同一题项反复保存、不同实验中的相同题都会在题库产生多条重复题目。
- 作业题目只有新增接口，缺少更新与删除接口；作业发布后仍可继续增删题目，没有锁定。
- 题库、作业、实验三处对同一道题的字段结构和校验标准不一致。

### 2.2 目标

1. 明确题库、作业、实验、考试的题目来源边界与复用方式。
2. 统一一道题在四处的内容契约与校验规则。
3. 把“题库”和“现场题目”之间的搬运，统一为一次性、显式、幂等、可追溯的复制。
4. 修复作业内联题的判分错误与重复追加问题。
5. 修复实验题项同步造成题库重复堆积的问题。

### 2.3 成功标准

- 作业内联的客观题保存后，学生端能完整看到选项，答对得分、答错 0 分、空答 0 分。
- 同一份作业编辑保存三次，题目数量不增加。
- 实验保存题项不再自动写入题库；同一题项手动复制多次，题库只产生一条对应题目。
- 多个实验包含相同题目时，题库中存在多条独立题目，但每条都能追溯到具体实验与题项。
- 题库题目修改后，已发布作业、考试、实验的展示与评分不受影响。

## 4. 范围

### 4.1 本期范围

- 统一题目内容契约：题型、题干、选项、标准答案、解析、评分参数。
- 作业内联题完整落库与统一校验（P0）。
- 作业编辑改为增量提交，新增题目更新/删除接口与发布后锁定（P1）。
- 作业“同时保存到题库”显式开关与幂等复制（P1）。
- 实验取消保存时自动同步，改为显式、幂等复制（P1）。
- 题库新增来源字段与复制来源追溯（P1）。
- 实验从题库预填题项（P2）。
- 复制时内容重复提示（P2）。

### 4.2 不在本期范围

- 学校级共享题库、题目审核流、题目版本管理。
- 作业/实验题目与题库的实时绑定或双向同步。
- 考试题目来源规则改造（沿用只允许题库题）。
- 主观题自动评分能力改造。
- 历史内联题、历史实验题项的数据回填与批量修复。
- 题库题目的跨教师迁移与交接。
- 题库题目批量导入能力（由 2026-11-05 PRD 覆盖）。

## 5. 术语

| 术语 | 定义 |
|---|---|
| 题库题（BANK） | 归属教师的可复用题目资产，存放在题库中 |
| 内联题（INLINE） | 仅在当前作业内存在、`questionId` 为空的题目 |
| 实验题项（LAB_ITEM） | 实验内的独立题目实体，带步骤号、步骤分、粘贴控制等实验专属属性 |
| 快照 | 题目加入作业/实验/考试时冻结的内容副本，运行时评分与展示只读快照 |
| 复制 | 把一处题目内容一次性复制为另一处的独立题目，复制后互不影响 |
| 预填 | 从题库读取题目内容填入实验题项编辑器，保存后成为独立题项 |
| 幂等 | 同一来源重复执行复制时，不产生新的题库题，返回已存在的题目 |

## 6. 核心流程

### 6.1 作业组题流程

1. 教师创建或编辑作业，选择目标班级。
2. 教师通过“从题库挑题”加入题库题，或通过“新增题目”录入内联题。
3. 内联题录入时必须填写完整题型、题干、选项、标准答案、解析、分值。
4. 保存时后端执行统一校验，通过后写入作业题目与题目快照。
5. 若勾选“同时保存到题库”，保存成功后执行单向复制；复制失败只提示，不回滚作业。
6. 发布后题目结构锁定，仅允许调整排序；分值不可改（见 2026-11-09 分值 PRD）。

### 6.2 实验组题流程

1. 教师创建实验，进入步骤与题项配置。
2. 教师录入题项，或通过“从题库选题”预填题项内容。
3. 教师补充步骤号、题项标题、步骤分、粘贴控制等实验属性。
4. 保存题项，生成独立实验题项，不写题库。
5. 需要沉淀时，教师点击“复制到题库”，系统按 `(labId, stepId)` 幂等执行。
6. 复制成功后展示题库题编号与跳转入口；重复操作返回已有题目。

### 6.3 复制流程通用规则

1. 复制是显式动作，不由保存动作隐式触发。
2. 复制前校验来源题目内容完整，不完整时禁止复制并提示缺失字段。
3. 复制使用独立事务，失败不影响来源题目。
4. 复制成功后写入 `source_type`、`source_ref`。
5. 复制后两边独立维护，任何一侧修改都不回写另一侧。

## 7. 功能需求

### FR-1 统一题目内容契约

**目标**：同一道题在题库、作业、实验、考试中使用同一套内容字段。

字段定义：

| 字段 | 说明 | 必填 |
|---|---|---|
| type | 题型：单选、多选、判断、填空、简答；代码题仅存在于实验内部，落题库时按简答映射 | 是 |
| stem | 题干 | 是 |
| options | 选项列表，结构固定为 `[{"key":"A","content":"..."}]`，客观题必填 | 客观题必填 |
| answer | 标准答案，统一数组形态，结构见 D5 | 是 |
| analysis | 解析 | 否 |
| scoringConfig | 评分参数：多选给分规则、填空匹配规则等，不存放标准答案 | 是 |

> `defaultScore` 已于 2026-11-09 废止：题库不再保存任何形式的分值，分值只在组卷配置中设置。见 `docs/PRD/2026-11-09-题目分值归属与组卷分值规范PRD.md`。

评分读取规则：

- `GradingAdapter` 先从 `answerJson` 推导答案键（`correctAnswer`、`correctAnswers`、`blanks`），再用 `scoringConfigJson` 覆盖评分参数；两者合并后交给评分策略。
- 不得因为 `scoringConfigJson` 非空而跳过 `answerJson` 推导，否则会出现“配置里有评分配置、标准答案却读不到”的判 0 分问题。
- 新写入数据统一使用 D5 定义的数组形态；历史对象形态（`correctAnswer`、`correct`、`answer`、`blanks` 等键）只在读取时兼容，不再写入。

要求：

- 作业内联题请求体新增 `optionsJson`、`answerJson`、`analysisText`，结构与题库一致。
- `scoringConfigJson` 仅保留评分参数，不再存放选项与标准答案。
- 评分适配层只读取上述统一结构，不再同时兼容两套键名。

### FR-2 题库（资产中心）

- 题库是教师个人的可复用题目资产，不做跨教师共享。
- 题库题新增 `source_type`、`source_ref`，取值与格式见 D14。
- 题库题被修改时提示影响面：已生成的快照不受影响，后续新引用使用新内容。
- 题库题允许物理删除；删除不影响已生成快照，界面提示“历史作业与考试不受影响，该题不可再被复用”。
- 题库列表展示来源标记，支持按来源筛选（P2）。

### FR-3 考试（沿用现有约束）

- 只能从题库选题，`questionId` 必填，`sourceType` 必须为 `BANK`。
- 加入时生成快照，发布前再次校验来源。
- 历史内联题数据只读，禁止发布，提示“请先保存到题库”。
- 已发布考试题目结构锁定。

### FR-4 作业双入口与内联题

- 保留“从题库挑题”和“新增内联题”两个入口。
- 内联题必须完整录入并落库选项、标准答案、解析。
- 客观题缺选项或缺答案时禁止保存，错误提示定位到具体字段。
- 学生端必须能按照快照渲染完整选项，并按标准答案评分。
- 内联题 `sourceType=INLINE`，`questionId` 为空，不自动进入题库。

### FR-5 作业“同时保存到题库”

- 位置：作业题目编辑区域，默认关闭；开关作用于本次提交的内联题。
- 交互：勾选后保存作业时，对本次提交的内联题执行复制。
- 幂等：同一作业题目只复制一次；已存在时返回已有题库题并提示“已保存到题库”，提供跳转。
- 重复复制不更新题库题内容；需要改内容时在题库侧手动编辑，或在后续迭代提供“更新已复制题目”。
- 失败处理：作业保存成功，复制失败提示原因并提供“重试复制”。
- 复制结果：题库题记录 `source_type=HOMEWORK_INLINE`、`source_ref=HOMEWORK:{homeworkQuestionId}`。
- 内容重复提示：若同教师题库已有同内容题目，提示并提供 `duplicateQuestionId` 跳转，不阻断复制。
- 同内容判定：对 `type + stem + optionsJson + answerJson` 规范化后计算 SHA-256；忽略解析、难度、分值与编码。
- 不做：作业题与题库题双向同步、自动更新。

### FR-6 作业编辑（增量提交）

- 草稿期支持新增、修改、删除、排序题目。
- 保存时只提交发生变化的题目，不允许把全部题目重复追加。
- 接口变更：
  - 新增：`POST /api/v1/teacher/homeworks/{id}/questions/inline`（已有）；
  - 从题库挑题：`POST /api/v1/teacher/homeworks/{id}/questions/bank`（已有）；
  - 更新：`PUT /api/v1/teacher/homeworks/{id}/questions/{homeworkQuestionId}`（新增，支持题干、选项、答案、解析、分值、排序）；
  - 删除：`DELETE /api/v1/teacher/homeworks/{id}/questions/{homeworkQuestionId}`（新增）。
- 已发布作业：禁止新增、修改、删除题目，仅允许调整排序；需要改题先撤回为草稿。
- 已有学生提交时：禁止删除题目、禁止修改分值；题干与选项修改只影响后续新作答，界面必须提示。

### FR-7 实验题项与双向复制

**题项独立**

- 实验题项不写 `question_id`，不依赖题库引用；历史 `question_id` / `question_snapshot_json` 字段保留，不做清理。
- 题项保留步骤号、标题、步骤分、粘贴控制、行为埋点等实验专属属性。

**实验到题库**

- 取消保存题项时自动创建题库题。
- 提供显式“复制到题库”动作，唯一入口为题项列表操作区按钮；保存成功后只提示复制结果，不再提供第二个入口。
- 复制前展示映射预览：题型、题干、选项、答案、难度、解析（题库无分值，不展示分值）。
- 代码题按简答题映射，教师确认后落库；题库不支持的题型（如实验附件、纯操作步骤）禁止复制并说明原因。
- 幂等键 `(labId, stepId)`，重复复制返回已有题库题。
- 题库题记录 `source_type=LAB_STEP`、`source_ref=LAB:{labId}:{stepId}`。

**题库到实验**

- 题项编辑器提供“从题库选题”。
- 选中后只预填题型、题干、选项、答案、解析；分值由组卷配置按题型默认分生成，题库不提供分值。题库 `answerJson` 写入题项 `answerConfigJson`，结构保持一致。
- 教师仍需补充步骤号、标题、步骤分、粘贴控制。
- 保存后生成独立题项，不写 `questionId`，与题库脱钩。

**实验深度拷贝**

- 复制题项内容，新题项归属新实验，`stepNo` 按新实验重新编排。
- 不自动复制题库题；旧题库题的 `source_ref` 仍指向旧实验，新实验再次复制会生成新的题库题。
- 不保留旧实验题项与题库题的绑定关系（当前也不存在该绑定）。

### FR-8 复制接口

| 接口 | 用途 | 幂等 |
|---|---|---|
| `POST /api/v1/teacher/homework-questions/{homeworkQuestionId}/copy-to-bank` | 作业内联题复制到题库 | 按来源键 `HOMEWORK:{homeworkQuestionId}` |
| `POST /api/v1/teacher/lab-steps/{stepId}/copy-to-bank` | 实验题项复制到题库 | 按来源键 `LAB:{labId}:{stepId}` |

请求体：

```json
{
  "code": "可选，缺省自动生成"
}
```

响应要求：

- 新建成功返回 `created=true`、`question` 题库题详情、`duplicateQuestionId`（可为空）；
- 已存在返回 `created=false`、`question` 已有题库题详情、`duplicateQuestionId`（可为空）；
- 两个场景均返回 HTTP 200；
- 内容不完整返回 40000 与缺失字段说明；
- 编码冲突返回 40900「题目编码已存在」；
- 无权限返回 40300；
- 实验题项复制时由后端按 `stepId` 反查 `labId`，不信任前端传入的来源键。

## 8. 业务规则汇总

### 8.1 校验矩阵

| 题型 | 必填校验 |
|---|---|
| 单选 | 选项不少于 2 个，标准答案必须是选项之一 |
| 多选 | 选项不少于 2 个，标准答案非空且全部在选项内 |
| 判断 | 标准答案为 `T` 或 `F` |
| 填空 | 至少 1 个空，每个空至少 1 个可接受答案 |
| 简答 | 题干非空，参考答案或评分要点非空 |
| 代码（仅实验内部） | 题干非空，参考答案或评分要点非空；复制到题库时映射为简答 |
| 全部 | 题干非空；组卷分值大于 0（题库侧不校验分值，见 2026-11-09 分值 PRD） |

前端与后端使用同一套规则，后端校验为准，前端负责即时提示。

### 8.2 状态与编辑权

| 状态 | 题目结构 | 分值 | 排序 | 删除题目 |
|---|---|---|---|---|
| 草稿 | 可增删改 | 有学生作答后不可改，否则可改 | 可改 | 允许（有学生作答时禁止） |
| 已发布 | 禁止增删改 | 不可改 | 可改 | 禁止 |
| 已截止/已归档 | 禁止 | 不可改 | 不可改 | 禁止 |

说明：已发布后有学生提交时，题干、选项、答案的修改不再允许；如需改题必须先撤回为草稿。

### 8.3 复制规则

| 规则 | 说明 |
|---|---|
| 无绑定 | 复制均为一次性内容搬运：题库到实验为预填，作业/实验到题库为沉淀；不建立实时引用或双向同步 |
| 显式 | 由教师点击或勾选触发，不随保存隐式执行 |
| 幂等 | 同一来源重复复制不新建，返回已有题目 |
| 可追溯 | 题库题记录来源类型与来源标识 |
| 失败隔离 | 复制失败不影响来源题目，可重试 |
| 独立维护 | 复制完成后两侧互不影响 |

### 8.4 快照规则

- 题库题加入作业、实验、考试时生成快照。
- 运行时的题干、选项、答案、解析、分值以快照为准。
- 题库题修改、删除均不影响已生成快照。
- 内联题与实验题项本身即为其快照来源，编辑后仅影响后续新生成的作答记录。

## 9. 数据与契约要求

### 9.1 数据变更

新增迁移 `V22__question_source_trace.sql`：

- `question_bank` 新增 `source_type VARCHAR(20)`，可空；
- `question_bank` 新增 `source_ref VARCHAR(100)`，可空；
- 存量行不回填：`source_type` 为 NULL 表示历史或未知来源，仅新建手工题写入 `MANUAL`；
- 新增唯一索引 `uk_question_bank_source_ref(source_ref)`，保证同一来源只生成一条题库题；
- 唯一索引允许多个 NULL，手工录入题目不受影响；MySQL 与 H2 对多个 NULL 的唯一索引行为一致；
- 新增普通索引 `idx_question_bank_source_type(source_type)`，供来源筛选使用；
- 不修改 V1–V21 历史脚本。

停用能力：本期不引入，列入后续迭代。

### 9.2 接口变更

- 作业内联题新增请求体增加 `optionsJson`、`answerJson`、`analysisText`。
- 新增作业题目更新、删除接口，路径见 FR-6；现有控制器只有新增接口，不存在可复用接口。
- 新增复制到题库接口两个，见 FR-8。
- 题库现有接口为 `/api/v1/questions`：列表返回 `optionsJson`、`answerJson`、`analysisText`，可直接用于实验预填；没有单题详情接口，本期不新增，预填从列表数据取。

### 9.3 兼容性

- 历史内联题快照中 `options` 为空的数据不自动修复；教师编辑保存后按新规则写入。
- 历史实验题项保持只读可用，不追溯清理题库中的历史重复题目。
- 历史考试的题库题来源规则不变。

## 10. 非功能需求

### 10.1 权限

- 教师只能访问、复制、修改自己的题库题目。
- 学生不可访问题库接口。
- 校管端不接入题目资产。

### 10.2 数据一致性

- 复制使用独立事务，失败不回滚主流程。
- 复制与快照写入必须在同一来源题目保存成功之后执行。
- 幂等校验与写入需在同一事务内完成；并发冲突由 `uk_question_bank_source_ref` 唯一索引兜底，捕获冲突后返回已有题目。

### 10.3 审计

- 复制到题库沿用现有 `QUESTION_CREATE` 审计。
- 审计记录需包含来源类型与来源标识，不记录题目答案明文以外的敏感信息。

### 10.4 性能

- 复制单题接口响应时间不超过 1 秒。
- 题库来源筛选与幂等查询走索引。

## 11. 异常与边界场景

| 场景 | 预期行为 |
|---|---|
| 内联客观题缺少选项 | 禁止保存，提示“客观题至少需要 2 个选项” |
| 内联客观题缺少标准答案 | 禁止保存，提示“请设置标准答案” |
| 学生提交空答案 | 判 0 分，不得因空集相等而得分 |
| 作业编辑重复保存 | 题目数量不变，内容按最后一次提交更新 |
| 已发布作业尝试新增、修改、删除题目 | 拒绝并提示先撤回 |
| 已有作答的题目被删除 | 拒绝删除，提示已有作答记录；如需调整先撤回并处理作答数据 |
| 实验题项重复复制 | 返回已有题库题，不新建 |
| 多个实验包含相同题 | 各自复制为独立题库题，来源分别记录 |
| 复制过程中题库服务异常 | 来源题目保持成功，提示复制失败并可重试 |
| 题库题被删除 | 不可再被新引用，历史快照不受影响 |
| 题库题被修改 | 新引用使用新内容，历史快照保持冻结 |
| 实验深度拷贝 | 题项复制到新实验，不复制题库题，旧题库题来源不变 |
| 代码题复制到题库 | 按简答题映射，复制前展示映射预览并由教师确认 |

## 12. 验收清单

### 12.1 P0：作业内联题

- [ ] 新增单选内联题，填写选项与答案后保存，重新打开作业，选项与答案完整回显。
- [ ] 学生端作答该题，选项正常展示；答对得分，答错 0 分，空答 0 分。
- [ ] 新增缺少选项或缺少答案的客观题，保存被拒绝，提示字段准确。
- [ ] 同一作业连续保存三次，题目数量保持不变。
- [ ] 草稿期作业内联题修改分值、题干、删除题目均生效，不产生重复记录。
- [ ] 已发布作业尝试新增、修改、删除题目被拒绝，调整排序成功。
- [ ] 已有学生提交后删除题目或修改分值被拒绝，提示准确。
- [ ] 作业编辑弹窗内修改题库题（BANK 行）后保存，只更新本作业快照，题库题内容不变。
- [ ] 在一次保存中同时修改题目并把状态改为“已发布”，保存成功且不触发“仅支持调整排序”拒绝。

### 12.2 P1：实验复制与来源追溯

- [ ] 保存实验题项时，题库不新增题目。
- [ ] 手动执行“复制到题库”，题库新增一条题目，来源记录为实验与题项。
- [ ] 同一题项重复执行复制，题库题目数量不增加，返回已有题目。
- [ ] 两个实验包含相同题目，分别复制后题库有两条独立题目，来源不同。
- [ ] 复制失败时题项保存成功，界面提示失败原因并可重试。
- [ ] 修改题库题后，实验题项内容不变；修改实验题项后，题库题内容不变。

### 12.3 P1：作业保存到题库

- [ ] 默认不勾选时，保存作业不创建题库题。
- [ ] 勾选后保存，题库新增题目并记录来源。
- [ ] 重复保存不重复创建题库题。
- [ ] 复制失败不影响作业保存，重试可成功。
- [ ] 题库已有同内容题目时，响应返回 `duplicateQuestionId`，界面提示但复制仍成功。
- [ ] 同一作业题重复复制，题库题内容不被覆盖。

### 12.4 P2：实验预填与重复提示

- [ ] 实验题项编辑器可从题库选题，选中后题型、题干、选项、答案、解析、分值正确预填。
- [ ] 预填后仍可修改步骤号、标题、步骤分、粘贴控制。
- [ ] 保存后题项与题库无绑定关系。
- [ ] 复制内容与题库已有题目相同时，提示“题库已有相同题目”，复制仍成功，不自动合并。
