### 1.1 已定决策清单

|---|---|---|
| D1 | “对标考试”的准确范围 | 三域统一**评分语义、文案口径、交互原则、共享展示函数**；不追求三域页面结构同形。作业保留「逐题保存 + 整卷评分」、实验保留「逐题 + 整卷 + 批量」；考试保持单一「保存评分」且**不新增**采纳建议分入口 |

## 3. 目标与非目标

### 3.1 目标

1. 教师进入任一域的批改界面，看到的评分语义、中文标签、参考分说明、只读提示与禁用样式一致。
2. 三域教师端不再出现后端调试串、英文枚举值与开发口吻文案。
3. 评分中间态实时反馈：显式评分才算已评分，未提交改动受保护，保存后停留在原页。
4. 共享展示函数与单测覆盖全部已知判分说明格式，后续新增题型只需扩一处映射。

### 3.2 非目标（明确否决）

| 非目标 | 结论与理由 |
|---|---|
| 后端状态机 / 成绩落库三份同构实现收敛 | 继承 11-17 PRD D8，继续单独立项；本期只做前端展示与交互 |
| 后端 `judgeDetail` 字符串改中文 | 会影响持久化数据与三域测试，前端映射即可满足教师可读性 |
| 三域页面结构强行统一为考试形态 | 作业逐题+整卷、实验批量批改是高频能力，删除即功能回归 |
| 考试开放采纳建议分 / 单题复核改分 | 继承 11-18 PRD 否决；考试维持教师手工给主观题分 |
| 新增成绩发布按钮 | 作业/实验现有发布/可见性链路保持不变 |
| 数据库、SQL、迁移、权限、契约变更 | 本期纯前端；不需要用户执行任何 SQL |

## 4. 需求明细

### FR-1 三域统一分数语义与汇总

1. 汇总区落点写死：考试在结果页右侧「评分汇总」卡；作业在批改弹窗「评分与反馈」区上方；实验在报告详情页「评分汇总」卡与批量页顶部汇总条。三域队列/列表分数行同步使用新标签，列表平均分统计页不在本期范围。
2. 汇总区固定三行：`客观题自动得分`、`主观题人工得分`、`总分`。
3. 考试以 `isCorrect === null` 判主观题，其余题目的 `autoScore` 计入自动分；作业与实验按 `scoreSource` 分流：`AUTO` / `AUTO_ACCEPTED` 计入自动分，`TEACHER` 计入人工分，`SUGGESTED` / `RECOMMENDED` 只作参考、不计入总分。
4. 总分 = 自动分 + 人工分，前端实时计算；实验满分取 `maxScore ?? stepScore`，作业满分取题目 `score`，考试满分取 `questionScore`；禁止硬编码 100。
5. 需要人工评分的题数为 0 时，考试与作业显示「本卷无主观题，系统已完成判分」，实验显示「本卷无需人工评分，系统已完成判分」；不显示 100% 进度条。其余情况显示「评分进度 x/y 题」与进度条。

### FR-2 判分说明与题型中文化

1. 三域教师批改页统一调用 `formatJudgeDetail(...)` 与 `questionTypeLabel(...)`，不得直接绑定 `judgeDetail` / `autoJudgeDetail` / `question.type`。
2. 映射表见 §4.2；未知值兜底「系统自动判定」，不得原样输出。
3. 客观/自动判分题的提示行固定包含：`scoreSource` 中文标签、映射后的判分说明、「客观题由系统判分，不支持修改」。

### FR-3 建议分与采纳

1. 参考分有值时显示「系统参考分 X（仅供参考，不直接计入）」；无值时整行不渲染。
2. 作业与实验保留采纳入口，按钮文案统一为「采纳参考分」；采纳后按现有后端语义更新 `score` 与 `scoreSource`，前端刷新总分与来源标签。
3. 考试不新增采纳入口；客观题不显示建议分。

### FR-4 只读、草稿与保存

1. 只读态判定按 D4；所有评分输入、采纳按钮、整卷/批量提交按钮在只读态禁用并灰化。
2. 未提交改动包含分数、评语、采纳动作；按 D9 在考试切题/刷新、作业切提交/关弹窗、实验详情切报告、实验批量页切换学生/班级与返回详情前确认；打回走 D10 独立确认。
3. 保存确认粒度按 D10；toast 文案按 D10 写死的三条字符串执行；打回只弹 D10 独立确认，不叠加 D9 草稿确认。
4. 保存成功后停留当前页并刷新状态（D12）。

### FR-5 共享层与类型

1. `scoreDisplay.ts` 新增 `formatJudgeDetail(...)` 与 `questionTypeLabel(...)`，并保留既有导出的行为不变。
2. `types/lab.ts` 的 `LabScoreSource` 补 `AUTO_ACCEPTED`。
3. 函数与类型落点唯一；三域页面通过 import 使用，不各自复制映射。

### 4.2 `formatJudgeDetail` 映射表（写死）

| 原始串（含前后缀） | 展示文案 |
|---|---|
| `single choice matched` | 答案匹配，系统自动给分 |
| `single choice mismatch` | 答案不匹配，系统判定 0 分 |
| `true/false matched` | 判断正确，系统自动给分 |
| `true/false mismatch` | 判断错误，系统判定 0 分 |
| `multiple choice mode=…, expected=…, actual=…` | 多选题按当前规则自动判定 |
| `blank N: matched` / `blank N: mismatch`（可多段） | 第 N 空匹配 / 第 N 空不匹配，多段用顿号连接 |
| `matched=[…]; length=x/y` | 系统按命中关键词与作答长度生成参考分 |
| `scoring engine unavailable` / `missing rule config` / `unsupported question type` | 自动判题暂不可用，请人工评分 |
| null / 空串 / 其它未知值 | 系统自动判定 |

`questionTypeLabel` 映射：`SINGLE_CHOICE`→单选题，`MULTIPLE_CHOICE`→多选题，`TRUE_FALSE`→判断题，`FILL_BLANK`→填空题，`SUBJECTIVE`→主观题；未知值→「其他题型」。

## 5. 验收标准

1. 三域教师批改页全局搜索：无 `single choice matched`、`true/false mismatch`、`blank 1:`、`expected=[`、`matched=[` 等原始串及其直接插值；英文题型不再出现在题型位置。
2. §4.2 映射表每一类输入均有对应中文展示；未知串显示「系统自动判定」，不泄漏原文。
3. 三域 `scoreSource` 标签覆盖 `AUTO`、`AUTO_ACCEPTED`、`SUGGESTED`、`RECOMMENDED`、`TEACHER`；实验类型定义含 `AUTO_ACCEPTED`。
4. 考试域回归：无主观题答卷显示「本卷无主观题」而非 100%；未评分主观题显示「待评分」；显式 0 计入已评分；`GRADED` 保持只读；既有 4 个单测全绿。
5. 作业域：汇总不再硬编码 `/100`；`GRADED` 时单题与整卷提交按钮均为禁用并灰化；未评分题不默认显示 0 分。
6. 实验域：报告详情与批量页使用同一套 `scoreSource` / 判分说明 / 参考分文案；`SAVED` 与 `GRADED` 均只读；满分取 `maxScore ?? stepScore`，无回退到 100 的兜底。
