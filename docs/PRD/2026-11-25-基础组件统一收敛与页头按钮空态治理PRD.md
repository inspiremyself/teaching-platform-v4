## 3. 目标与非目标

### 3.1 目标

1. 全站页头、工具条、表格卡、状态、空态、按钮只有一种实现口径，三域与非三域页面共用同一套基础件。
2. 三域内部不再出现“列表页一套、详情/批改页另一套”的按钮与空态写法。
3. 非三域页面复用同一套 L0–L2 基础件，但保留教师管理台、学生任务流、校管治理视角的编排差异。
4. 设计规范只有一份事实源，功能文档只引用不重定义，新增页面有固定的 UI 影响面清单。
5. 防止回潮：新增页头、第二套按钮写法、新增空态画法会被 `npm test` 拦截。

### 3.2 非目标（明确否决）

| 非目标 | 结论与理由 |
|---|---|
| 把三域与非三域页面改成同一套布局模板 | 否决：违反 D1/D2 与 `AGENTS.md` 三角色信息节奏约束 |
| 合并三套角色壳层或路由树 | 否决：角色边界与权限语义固定 |
| 重构 `WorkbenchShell` / `GradingWorkspace` / 三栏批改布局 | 否决：11-19 已交付验证，本期只替换内部基础件写法 |
| 新增 Element Plus 按钮 / 输入框 / 表格包装层 | 否决：11-24 D12 已定门槛，属于过度封装 |
| 全量重写 49 个 scoped 样式块 | 否决：回归面不可控，改为按期、按页迁移 |
| 一次性清零 1279 处颜色字面量 | 否决：风险与收益不匹配，改为分批下降并锁定基线 |
| 用截图快照测试做视觉回归 | 否决：需新增浏览器依赖与图片基线仓库，超出既有工具链 |
| 在功能 PRD 中重新定义颜色 / 字号 / 按钮规格 | 否决：会造成第二套规范，违背 D10 |

## 4. 需求明细

### 4.1 P0 · FR-1 页头唯一化

1. 删除 `frontend/src/components/ui/AppPageHeader.vue`，同步删除 `assets/layout.css` 中 `.page-header*` 全部规则（`__main` / `__actions` / `__meta` / `__meta-item` / `__meta-item--accent` / `h1` / `p` / `strong` 及响应式覆盖）。
2. `assets/global.css` 的 `.workbench-header` 系列确认为全站唯一页头骨架；页面只允许通过附加类调整外观，不得复制骨架规则。
3. 学生 `Labs.vue` 页头由 `labs-header-card` 改为 `workbench-header labs-header-card`；`.workbench-header` 已提供 `--radius-xl`（16px）圆角与卡片骨架，`labs-header-card` 只保留 `__stats` 布局与确有差异的尺寸声明，删除重复的 `padding / border / border-radius / background / box-shadow`，不参与骨架语义。
4. `components/ui/` 剩余 5 个组件，全部有实际引用；禁止保留零引用组件。
5. 门禁中与 `AppPageHeader` / `.page-header` 相关的断言（含标题层级 `h1`）统一改为针对 `.workbench-header` 与“`components/ui` 无零引用组件”；不得留下指向已删除文件或已删除类的断言。

### 4.2 P1 · FR-2 workbench 按钮写法唯一化

1. `views/teacher/components/workbench/ActionButton.vue` 为 workbench 内部唯一按钮写法；现有 `label / tone / disabled` 覆盖模板迁移；为承接 `ExamListPanel` 现网尺寸，仅新增 `size?: 'default' | 'roomy'`（`roomy` = 16px 圆角、10px 12px padding），不新增其它视觉；确需新能力时先登记。
2. 以下 7 个模板文件的裸 `<button class="action-button ...">` 全部替换为 `<ActionButton tone="..." label="..." :disabled="..." @click="..." />`：
   - `teacher/LabGradingWorkspace.vue`
   - `teacher/HomeworkSubmissions.vue`
   - `teacher/exams/Results.vue`
   - `teacher/LabReportDetail.vue`
   - `teacher/LabReportBatchGrade.vue`
   - `teacher/LabSubmissionOverview.vue`
   - `teacher/components/workbench/TaskEditorDialog.vue`
3. `teacher/components/ExamListPanel.vue` 删除 5 条 scoped `.action-button*` 规则（现网为 16px 圆角 / 10px 12px padding，与 `workbench.css` 的 8px / 32px 不同），改用 `<ActionButton size="roomy" ...>`；`size="roomy"` 规则只写在 `workbench.css`，**尺寸与现网一致、tone 色板统一由 `workbench.css` 供值**（`--ghost` 文字色 `#334155`→`#475569` 并新增 1px `#DBE4F0` 边框，见技术方案 §3.10 V6）；`size="roomy"` 追加在 `tone` 之后以保住 `taskListUiConsistency.spec.ts` 的属性前缀断言。
4. `.action-button` 样式只保留在 `workbench.css`；workbench 目录之外的任何文件不得出现 `action-button` 字样（`ExamListPanel` 通过 `size` prop 间接使用）。
5. 非 workbench 页面统一使用 `el-button`，沿用 11-24 D15 的形态与尺寸，不保留自定义按钮类。

### 4.3 P2 · FR-3 空态唯一化 / FR-4 状态与元信息

**FR-3 空态**

1. 页面级空态与错误态统一 `AppEmptyState`；`tone="error"` 只用于加载失败，并提供“重新加载”动作。
2. `el-table` 内空数据继续使用 `empty-text`，不嵌入卡片。
3. 除 `AppEmptyState.vue` 自身实现外，`el-empty` / `el-result` 全部迁移；三栏批改台的“暂无提交”空态同样迁移（空态不属于布局结构）。
4. 迁移后 `el-empty` / `el-result` 计数写入基线，只降不升。

## 9. 已否决方案

| 方案 | 否决理由 |
|---|---|
| 保留 `AppPageHeader` 并把 20 个页面逐个迁移过去 | 20 个页头存在标题行、统计行、动作区等多种变体，迁移回归面大；零引用组件的维护成本高于收益 |
| 把 `workbench-header` 改名为通用语义类 | 需要机械改动 20 个文件与两份 CSS，收益仅为命名语义；本期登记为命名债，改名另立 PRD |
| 新建全站 `AppButton` 包装组件 | 与 11-24 D12/D15 冲突，且 Element Plus 已覆盖页面按钮需求 |
| 在 `ActionButton` 之外再保留裸 class 写法 | 同一体系两套写法会持续分叉，违背“同一操作只有一种表达”的目标 |
| 保留 `ExamListPanel` 的 scoped `.action-button` 覆盖 | 同一按钮两处定义，与 D4 冲突；改为 `ActionButton size="roomy"` 唯一变体，视觉不变 |
| 把 `Analysis.vue` 的 `analysis-card` 迁入 `AppTableCard` | 该卡片是领域分析卡，不是工具条或表格容器；强行归并会破坏分析页信息编排，违反 D1 |
| 一次性替换全部 `el-tag` / `el-empty` | 机械替换回归面大；改为“同一状态画法唯一 + 按页迁移” |
| 用文档规范替代代码收敛 | 现有问题正是代码层重复实现，文档无法约束存量与新增页面 |
| 本期强制颜色字面量清零 | 1279 处存量，收益与风险不匹配；改为分批下降并锁定基线 |
