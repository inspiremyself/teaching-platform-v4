### 2.4 影响面

- N1：生产实例可被公开口令接管校管权限，属可直接利用的未授权访问。

## 3. 目标与成功标准

### 3.1 目标

1. `prod` 实例不含可登录演示账号，`local` / `test` 演示账号与探活脚本保持可用。
2. 考试域教师权限与实验/作业域对齐，任教关系与学校归属撤销后即时生效。
3. 客观题评分只认题目答案，评分配置无法篡改答案键。
4. 实验代码题切题不串答案、不覆盖已输入内容。
5. 考试倒计时归零只交卷一次，不留悬空定时器。
6. 查重详情与选中任务始终一致，复核评语按任务隔离。
7. 作业/实验批改回退时清除残留成绩记录，统计与成绩单不再展示已撤销分数。

### 3.2 成功标准

- 在**已含 `V1`–`V24` 应用记录的临时库**上验证（不使用全新空库，避开 §4.2 的 X2 未实测迁移链）：启动前把 `t9001`、`20260001`、`admin9001`、`20260002`、`t9002` 五行的 `status` 置回 `ACTIVE`，以 `prod` profile 启动后这 5 个账号用 `123456` 登录均失败（返回 `40103` 账号停用），库中 5 行 `status` 变为 `DISABLED`；再次启动验证幂等，两次启动日志均无 Flyway missing / ignored migration；以 `local` / H2 `test` 启动并执行 `./scripts/common/healthcheck-login.sh` 仍探活成功。
