### 2.2 要解决的问题

1. **LAB 查重链路已断**：1B 把它登记为「遗留 SQL 未带学校条件」，实测比登记更严重——运行时新数据的 LAB 查重任务业务名永远是「未知活动」，教师看不到本校 LAB 任务、详情与复核被 `40300` 拒绝。这是本期最高优先级。
2. **跨校定位错误码口径分裂**：1B 的 6 表跨校已统一 `40400`（不泄露存在性），但教师「拥有」类入口与 `course_material` 仍返回 `40300`，且 `findOwnedMaterial` 完全没有按校定位。1B PRD §4.3:135 已写明「统一为 `40400` 属现网契约变更，另立需求处理」，本期即该需求。
3. **阶段 2 前置的读侧计数错误**：教师跨校任教时 `countDistinctActiveClassesByTeacherUserId` 会把他校活跃班级计入 `classCount`。`class_member` 等同类表经核对不构成真实风险，不跟进。
4. **遗留对象无台账**：`SCHEMA.md` 没有独立小节登记遗留表、孤儿表与「有列但读侧未过滤」的已知事实，阶段 2 建新模型时容易被误当成可复用资产。

4. 全程零迁移、零前端改动、零 API 契约变化，为阶段 2 提供干净基线。
