# 路径 B：H2 数据备份与恢复（历史索引 · 重定向）

> 本文已合并并重定向至 [本地数据备份与恢复](./2026-09-09-本地数据备份与恢复.md)，不再维护独立的 H2 说明。

现行入口（默认 MySQL 表结构 + 数据）：

| 操作 | 脚本 |
|---|---|
| 备份 | `./scripts/common/backup-local-data.sh --label <简述> --with-files` |
| 校验 | `./scripts/common/verify-local-backup.sh --latest` |
| 恢复 | `./scripts/common/restore-local-data.sh --latest --with-files` |

H2 文件库的专用场景仍可使用 `backup-path-b-data.sh` 与 `restore-path-b-data.sh`（历史入口）；清库只能走 `./scripts/path-b/reset-h2.sh`，禁止直接删除 `data/h2/`。数据门禁见 `.cursor/rules/path-b-data-backup-gate.mdc` 与 `protect-data-directory.mdc`。
