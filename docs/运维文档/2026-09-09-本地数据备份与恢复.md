# 本地数据备份与恢复

**创建日期**：2026-09-09（2026-09-09 增补 MySQL）  
**适用场景**：日常默认 **MySQL** 联调；Flyway 迁移、覆盖库、重构前防止业务数据丢失；可选 H2 文件库备份。  
**配套脚本**：

| 用途 | 主脚本 | 别名（转发） |
|------|--------|--------------|
| MySQL 备份 | `backup-local-data.sh` | — |
| H2 备份 | `backup-local-data.sh --h2-only` | `backup-path-b-data.sh` |
| MySQL 恢复 | `restore-local-data.sh` | — |
| H2 恢复 | `restore-path-b-data.sh` | — |
| 校验 | `verify-local-backup.sh` | `verify-path-b-backup.sh` |
| H2 清库 | `path-b/reset-h2.sh` | 内置 H2 备份 |

**Agent 规则/技能**：`.cursor/rules/path-b-data-backup-gate.mdc`、`.cursor/skills/local-data-backup/SKILL.md`

### 示例用法

```bash
# 破坏性操作前（默认 MySQL 表结构 + 数据 + 可选上传）
./scripts/common/backup-local-data.sh --label before-migration --with-files
./scripts/common/verify-local-backup.sh --latest

# 同时保留 H2 副本（例如 migrate 前）
./scripts/common/backup-local-data.sh --label dual --with-files --h2

# MySQL 恢复（须先停后端）
./scripts/common/restore-local-data.sh --latest --with-files

# 列出所有备份
./scripts/common/backup-local-data.sh --list

# 仅 H2（无 MySQL 时）
./scripts/common/backup-path-b-data.sh --label h2-only --with-files
./scripts/path-b/reset-h2.sh --label before-reset
```

## 0. 数据分层

| 层级 | 存储 | DROP / 清库后 |
|------|------|---------------|
| Flyway 种子 | `db/migration/` | 自动回来（演示账号） |
| 本地业务数据 | MySQL 或 H2 中的业务表 | **丢失**（靠备份恢复） |
| 上传 | `data/files/` | 不随库恢复（`--with-files`） |

---

## 1. MySQL 备份（默认）

`backup-local-data.sh` 使用 `mysqldump`，单次导出含：

- 表结构（`CREATE TABLE`）
- 表数据（`INSERT`）
- 触发器、存储过程、事件（`--triggers --routines --events`）
- 事务一致性（`--single-transaction`）

输出路径：

```text
data/backups/<YYYY-MM-DD_HHMMSS>[_label]/
  manifest.json
  mysql/teaching_platform.sql
  files/          # --with-files
  h2/             # --h2
```

默认连接（与 `path-b/backend.sh` 一致）：

| 变量 | 默认 |
|------|------|
| `DB_HOST` | `127.0.0.1` |
| `DB_PORT` | `3306` |
| `DB_NAME` | `teaching_platform` |
| `DB_USER` | `root` |
| `DB_PASS` | `12345678` |

**MySQL 备份可在后端运行时执行**（InnoDB 一致性快照）；**恢复仍须停后端**。

---

## 2. MySQL 恢复

```bash
./scripts/common/restore-local-data.sh --backup data/backups/2026-09-09_103000_label
./scripts/common/restore-local-data.sh --latest --with-files --force
```

流程：`DROP DATABASE` → `CREATE DATABASE` → 导入 `mysql/teaching_platform.sql`。

## 5. 成功判据

**MySQL 备份**

- 退出码 `0`，输出 `完成: data/backups/...`
- 存在 `mysql/teaching_platform.sql`（含 `CREATE TABLE`）
- `verify-local-backup.sh --latest` 通过

**MySQL 恢复**

- 退出码 `0`
- 重启后端后探活通过；自定义账号可登录（若备份中含该数据）
